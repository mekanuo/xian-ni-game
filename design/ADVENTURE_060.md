# 0.6 局部设计：背墙旧窑

2026-09-11。**第三修订空间白盒与物件后果已实测，进入正式生产；新图/人物/迁移/美术尚未交付。** 0.5 先完成发行；本稿由根代理在既有自主授权内收敛。承接已认可的空间冒险与角色扮演方向，保留现有核心动词。前两份石坳稿的停工放行、落石高径方案继续搁置；不要求每张地图发明新机制，要求熟悉动作在新地形与人物条件下有明确用途。

## 体验合同

玩家想亲自找通溪道与旧渠高岸之间的旧窑路。窑墙把路和施术来向分开：落地挡屏既能挡住来袭，也遮住自己的火球；挪开或烧掉之后，过去借用的遮蔽就变了。能打赢不是唯一结果，认清露身位置、分隔争夺者、绕出另一端同样算走通。

主循环是察看墙角与来向 → 选站位和手段 → 亲自穿过 → 从另一端继续旧地图的事务 → 选择原路或旧路返回。此次以较紧张的短段冒险承接0.5的同行归来，不再追加一条跟NPC走路的任务。

核心动词仍是步行、察看、引力术、火焰球、护符。没有新增境界、货币、装备刷取、攀爬、持盾墙或敌人刷新。整体预期一段约10分钟的新路探索，实际时长待白盒记录，不能把等待NPC或加长空路当内容。

## 世界与来源

恒岳失去山门后的初期与王林既有经历不动；原创低阶修士不替他夺门、取宝或救人。依据沿用 [SOURCE_SCOPE](SOURCE_SCOPE.md) 与 [事实底稿的改编入口](../docs/research/analysis/SOURCE_BIBLE.md)：基础控轻物和施火、观察试探、改变交战条件、有限借用和归还属于 adaptable；旧窑、杜芹、两名占道散修及新道路连接均为 open。不给宗门变故补日期，不把当地争夺写成原作记载的事件。

杜芹是仍在整理旧窑晾坯区的普通陶作人。她待在完整窑墙遮住的西院，只管自己的物件和棚角，不替玩家担保窑外是否安全。散修守在外路可见的站位，按实际视线、警觉和末见位置行动；不声称已有复杂绕墙包抄或固定巡逻。

## 双出口与范围

仅一张新图，两个真实出口。溪道北侧既有土路接旧窑西院，旧窑另一端接旧渠西侧高岸；确切接点须先验证地形、碰撞、路牌避让与往返，不能用“后续开放”牌代替出口。首次入口在0.5回程完成后出现，独行完成同样可进入，不要求许照加入。

玩家须亲自跨到另一端才记走通；只看路牌、答应借屏或到访西院不记完成。两端均能进入，返回时保留敌人退出、物件位置和烧毁结果。不补算清渠、同行或首章成果，已有区域的事务按原条件继续。

白盒只放西院、两处墙角、一块轻木挡屏、两名现有类型的远程对手和东西出口。外围硬墙、窑口与退身位共同限制射线；不堆箱槽机关、第三名敌人或新的工序。最先证明一处对射／转角局面，成立后才连成完整小地图。

## 代表局面与可预判的变化

入口的完整墙背提供第一处安全观察位。下一段能看见挡屏、屏外对手起手的位置，以及从墙侧绕去另一面的路。地面明示屏的落地底边与墙缺口，观测只给玩家眼前可见信息，没有穿墙透视迷雾的额外系统。

| 当前处境 | 合用的动作 | 真实变化与后续代价 |
|---|---|---|
| 玩家在挡屏后，对手从正面起手 | 留屏观察、沿墙角换位置；需要新遮蔽时牵到另一处并放下 | 落地后的屏在新位置挡双方射线；原位置不再提供掩护。牵物本身不让玩家同时施火。 |
| 玩家已绕到屏的另一侧，对手仍朝先前位置搜寻 | 从新的无遮挡角度打断，或趁对手去看实际落物点时绕行 | 对手只读取听见／看见的来向，不隔墙知道玩家位置；屏仍可留作返程退身位。 |
| 屏挡住当前所需的射线或退路，玩家决定烧开 | 明确瞄准可燃屏施火，等其烧毁后再经过 | 燃烧期间仍是实体，烧完才失去碰撞；永久开口同时丢掉遮蔽。未被击退的对手仍在，不能立刻清场宣布安全。 |
| 零灵力或不愿交战 | 借完整窑墙察看警觉、换角度走另一侧，必要时退回西院 | 必须能通过并撤回；可见暴露段需要判断，不以长空路或资源奖励衬托施术。若任何状态下闭眼沿同一路走都安全顺手，就调整墙角／对手站位，而非加伤害。 |

主要反例：在屏后朝对手直放火应被自己的遮挡截住；挪屏后重复站回旧位置不能继续受保护。对手已退出时，可以直接穿过，不强造第二轮危险。保留、挪动、烧毁的取舍来自具体来向和退路，不能只差结算台词。

留势仍按当前玩法用于腾出手；**本候选不以悬空挡屏的实体遮蔽成立为前提**。可靠截弹使用实际落地屏与固定窑墙。0.5已补齐连续射弹首碰，下一白盒需复核它在这段地形的表现。

## 杜芹的借用与归来回应

她正在挡风晾坯，轻木屏是她的东西。首次靠近便能看见屏与工作面的关系；她说：“屏可以借。回来放在檐口这边，别烧了，我还要挡风。”这是物件使用约定，不是一句点头就把外路敌人清掉的通行许可。

- 愿意借：经她同意，实际把屏借离她看得见的晾坯作业面才记借用；后来将完好的屏放回她指出的原工作位置，她便腾出棚角供以后静息。只是答应或在原位轻挪不算借还。她认可的是自己能目睹的借还，不要求或声称知道玩家是否已跨到另一出口；新路完成仍由玩家真实跨出单独成立。
- 不借或自行绕行：外路同样可以通过；她继续自己的工作，不追着玩家发任务，也不把未借的屏说成欠债。
- 借后烧毁或把屏留在外路：屏始终属于本图物件，切图按既有规则放下并留在本图，不进入行囊或跨图运输。如实保留屏的状态，她不交出棚角；玩家仍可借原有安全点休整。不能用一次重访洗掉烧毁，也不临时索要新货币或刷材料抵债。
- 尚未归还：可以继续回来履行；经过别的出口、隔图交谈或许照跟来，都不能替玩家归还物件。

棚角只是一个有由来的次要便利，新路本身才是本章成果。它不新增法器能力、额外灵力上限或奖励数值。杜芹只知道自己目睹的借还与物件现状；不凭空评价玩家用了哪条外路、如何击退散修。

玩家可见状态只保留到访、实际跨出的出口、是否借走、是否完好归位／烧毁、是否获得棚角使用约定。各自回读在当前提示、杜芹行为、地面物件和可用静息点，不添加总好感条或第二本任务账。

## 反馈、失败与验证切片

第一分钟先看窑墙、借屏条件和第一处退身位，不先开长对白。选术、第一撞击点、屏的落地／燃烧、对手起手须同一画面可辨；敌我术法碰墙采用已验证的撞击反馈，移动落物沿用实际声响引敌。人物和路牌的字仍贴对应对象，不加白色导航线。

体力、灵力、伤药、暂停和重试均沿用既有规则。退到安全西院可离场；受击说明实际来向。重试恢复进入该处境的物件、敌人、资源和借用事实，不让玩家重试复制棚角许可。暂停不推进射弹、燃烧或关系事件。

白盒固定同一地形与对手初态，分别实际走：保留屏换角度跨出并返程；挪屏借用后完好归位；烧屏后从同一处再接近；零灵力步行通过并撤回。记录输入、站位、首个碰撞、敌方末见位置、资源与最终出口，不在调试接口注入完成。

最大风险是可见地形不能支持这几种走法，或低资源路径被固定对手永久堵住。先在目标运行环境验证这一点，失败便局部改地形或缩减一名对手，不增加新系统补救。角色条件、归还与旧档另有模型边界；手感、压迫感和趣味不能由测试宣布通过。
