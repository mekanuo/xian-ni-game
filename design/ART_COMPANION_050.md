# 0.5 许照带回程：最小美术表现规格

2026-09-11。**美术增量已接入0.5候选，尚待浏览器截图与实际输入核对。** 只覆盖 [COMPANION_050](COMPANION_050.md) 的工棚领路、雨棚歇脚与归家补笔；继承 [ART_DIRECTION](ART_DIRECTION.md) 和 [ART_CANAL_040](ART_CANAL_040.md) 已建立的材质、明度、脚点和状态表达。最新交接与用户授权覆盖旧美术总稿的历史“待确认”标题，本稿不另发起风格确认。

核心画面是许照在前面真正走、在转弯处真正停，玩家自己赶上。质感来自原画、脚下关系、克制动作与留下的物件，不依靠新增地图、发光路径、白线或常驻任务面板。坐标和动作幅度均为候选；最终以规则路径、安全候点与桌面/手机画面核对为准。

## 1. 最少的三处变化

| 场所 | 玩家应看见什么 | 采用与否决 |
|---|---|---|
| 工棚回程 | 熟悉的许照走在前方，药篓和苔青衣襟可辨；岔路石刻与旧绳结帮助认方向；停步朝向说明她在等谁或看什么 | 原角色、原路材质与两处小地标。不要角色脚下箭头、人物间连线、地面连续脚印或全程导航轨迹。 |
| 溪道雨棚 | 原有器具箱仍在，干地多一只低矮织草坐垫，位置让人能走近歇脚 | 复用已有精细坐垫原画；不再铺大地板、添新棚、生成第二只药筐或改变导水板。 |
| 回石驿桌边 | 首章图和旧渠小图都保留；一张窄纸签记个人回程，实际共同走过并回家补笔后，才多许照的辨路短记号 | 同一张纸的可辨增量。不要整张地图换皮、好感徽章、金色完成章或“同行成功”大遮罩。 |

整体保持中高明度，石青/苔绿/旧木棕与现有材质同源。状态首先由人物位置、朝向、物件出现与线形区别承担，颜色只辅助；不把危险路涂红、北路涂绿暗示未经模型证明的安全。

## 2. 许照的领路与等候

继续使用 `characters` 的 `3` 帧（源图当前裁框 `[754,627,327,627]`）、原药篓和人物尺度，不复制邵禾或生成另一张脸。脚影留在模型位置，图片小幅摆动；角色容器不为动画离开寻路坐标。

| 真实状态 | 最低限度的画面 | 对原因与事实的要求 |
|---|---|---|
| 尚未到工棚约定出发 | 沿用既有站位/普通跟随，原名“许照” | 家中接受事务不让她立即做领路姿态，不提前投放整条路的完成痕迹。 |
| `leading` 且身体实际移动 | 朝当前步行方向翻转，衣身约 ±1.5°–2°轻摆；脚影不移动、不闪烁 | 动作读取实际位移，不因为 phase 字符串等于 leading 就原地跑。前方受阻、对白或暂停时停止步态。 |
| 因玩家落后而 `waiting` | 在规则选定的安全弯处站稳，身体摆动回零，脸侧向玩家；保持药篓轮廓 | 原画只能表达左右朝向，不称为新增完整回头动画。第一次进入此原因时留一句“我在石刻边等你”，不每帧喊话。 |
| 因兽情而 `waiting` | 停在真实安全侧，面向实际威胁方向；肩身微收约 2°，保持脚点；附近原兽的起手/警觉仍清楚 | 提示“前面有兽，我先在这里等”，不得把暂停当成关系破裂，不在她头上新增红血条/惊叹号雨。 |
| 未约定 / 中止 / 受伤避险 | 回到已有静立或 `sheltered` 表现 | 不展示已经商定的路线，不使用“在出口等你”指向她没走到的地方。 |
| `exitReady` | 她站在真正抵达的出口候点，面向玩家或出口；已有出口牌仍为第一交互指向 | 不闪烁、挥手循环或自动切图；双方到达证据由规则给出，人物到场不能替代经过记录。 |

表示等候优先使用人物停步/朝向和既有“察看周围”的一句原因；名称牌仍是“许照”，仍锚在真实脚点下。不要为了等候状态把名字换成长句、叠第二块人物标签或移动标签到别人的物件上。进入等候的短句复用事件提示即可，原因未改变不重复。

暂停、对白、失焦、存档载入均冻结步态与过渡。减少动态时取消摆身和过渡，只保留方向、停步与短句；受击反馈继续优先，不能被领路姿态覆盖。只有前后实际朝向明确的情况才翻转，不每帧按玩家横坐标抖动。

## 3. 两个路边识别点

均为低矮环境识别物，不是可牵奖励、强制收集点或新障碍。不沿整条路重复盖章；识别物的存在不等于玩家或许照已经经过。

| 地标 | 材质与候选尺寸 | 候选位置 / 表现 |
|---|---|---|
| 北弯石刻 | 复用 `journey-props/stele`（`[484,423,277,360]`），约 `33×43` 世界单位，轻苔、自然比例。石面刻两条浅短折痕，1px 左右暗槽加低透明浅边；不刻小号假中文 | 工棚西北转弯近 `(335,255)`，最终让规则候点和行路净空决定。刻痕画在石面本地坐标内，不飘在空中，不因尚未走过就先亮起“已核对”。 |
| 南林旧绳结 | 复用 `journey-props/rope`（`[845,487,379,265]`），约 `36×25`，旧麻绳与木桩纹理，地面细短接触影 | 南侧近路边近 `(1050,830)`，避开草堆、空筐与实际站位；不把绳桩拉成阻拦全路的横绳。它只帮助辨路，不表示前方兽已退去。 |

形状即可区别两路：石面折痕与木桩绳扣。需要文字时用既有附近物名/察看说明，文本在 DOM 或 Phaser 的真实标签中绘制；不重做出口牌，不往原画中生成字。候选两点必须由规则计划核对当前障碍、活兽视线与寻路，不能因为美术先画了位置就把它设成安全候点。

地标细节可降级为现有原画加浅刻痕；脚点一致、方向信息不撒谎与通道留白不可降级。三张地面原画保持原样，不给地面新增连续道路色带；沿用旧渠精修教训，不把指向线画成贴地线路板。

## 4. 雨棚歇脚处

现有 `paintCreek` 把雨棚建筑放在 `(1090,600)`，显示 `420×220`；`shelter` 交互实体在 `(1200,500)`，其画面是工具箱与卷垫原画，不是第二座棚。新坐垫先以 `(1250,550)` 为候选脚点，规则校验干地、可近身、棚柱和药筐后才能锁定。不要为挤下坐垫改棚、桥或药筐的坐标。

复用 `detail-props/rest`（`[426,735,399,305]`）：麻布面、编草边的圆坐垫，建议 `70×45` 世界单位，`origin(.5,1)`，本地底脚沿用现有 rest 图像约 `(0,3)`。保持布纹与编织细节，不改画扁平绿色椭圆。坐垫只占低地面层，玩家/NPC在其前走过时脚影和衣摆可读；不能为深度把坐垫抬到人物腰部。

- 未开放：`journey_rest_shelter` 保持隐藏，不先画半透明奖励轮廓；原器具箱里的物件不因新设计自动消失。
- 玩家实际到棚内完成安放：规则先确认 `restOpened`，再显出同一坐垫。最多一次约 0.2 秒轻微落定（1–2 世界单位图片偏移，容器不动），或直接出现并配放下布垫的短声；不挪人物、不制造假搬运。
- 圆坐垫不适合“长席自动展开”的动画。画面表现为从现成物中取出、铺好；不把单张原画拉成长毯，也不宣称有完整取垫坐下逐帧动作。
- 再来：坐垫保持同一位置，可再次静息；第一次开放提示不重放，不叠第二只坐垫。独行也能开放，不能把有无许照作为图像显示条件。

歇脚效果沿用既有 rest 的成功/恢复反馈；附近水声与雨棚材质保持一致，不为普通休息播放胜利旋律。使用时若没有新坐姿资产，保留站在垫旁的静息反馈即可，不用把角色整体缩短来伪造坐下。

## 5. 回家纸图与两种笔迹

当前桌案已画首章路线（本地约 `x=-37..35,y=-55..-35`）与旧渠纸图（约 `x=21..51,y=-47..-23`）。新回程记录采用**桌面左前侧窄纸签**，实施时查看桌案母版后采用本地框 `x=-65..-40,y=-57..-41`，宽25、高16；原候选落到桌前沿，已修正，仍须在浏览器核对碗与桌边遮挡，不覆盖旧渠图及原路线。

| 真实记录 | 纸上形状 | 何时出现 |
|---|---|---|
| 尚未归驿落笔 | 不显示新纸签 | 即使已经答应同行、到出口或铺好坐垫，也不得提前成为桌面完成纪念。 |
| 独行归来 | 暖米白薄纸、一条石青细线、单独起讫短横；北路线偏高处折回，南路线偏下处弯过，mixed 保留转折 | 新主线 `complete` 且有实际个人路线记录。图形不靠颜色区别路线。 |
| 首次共同走完并归驿落笔 | 同样纸签与玩家实走线，附一对较短、不同斜率的苔青路边刻记 | 读取已经落笔的 `recordedShared` 和实际 `sharedRoute`，不能仅依 `agreed=together`、guide终点或旧渠共同标记出现。 |
| 先独行、后来实际共同回来补笔 | 原个人路线保留，在纸签空白侧补许照短记号；若两次走法不同，用小分支保留差别 | 只有本次真实回驿桌案交互结算后增加；不换掉旧纸、不重领坐垫，不把第一次独行改写成两人同走。 |

纸张 1px 内细边、很浅的纸下接触影，不用高饱和金光或红章。许照的两笔不是姓名签名，不生成不可读的“手写中文字”；谁画了什么由桌边现有对白/记事说明。只有她实际共同走过的部分能留下她的笔迹，不复用旧渠 `sharedInspect/sharedVerify`、首章 `travelInvited` 充当本段证明。

## 6. 当前代码接入点与职责

以下是按当前代码阅读形成的接入建议，不是已经实现的函数或已通过测试的接口。

| 文件 / 已有位置 | 适合接入的内容 | 必须守住的边界 |
|---|---|---|

| `scene.ts` 的 `drawEntities` NPC image 分支 | 现仅 `following/chasing/helping` 摆动；增加专项领路的表现选择，按本帧真实位移决定走/停，受击优先 | `leading` 名义状态不能当作已行走；局部图片姿态与权威 facing 分开，阴影仍留原脚点。 |

| `scene.ts` 的 `drawHomeState` 与 `drawEntities` 的 `stateKey` | 在原首章与 `drawCanalHomeRecord` 之后绘回程纸签；可以新增独立 `journey-art.ts` 只读绘图函数 | 缓存键需覆盖新主线完成、实际路线、recordedShared；否则“后来补笔”可能事实已变、画面没刷。不要修改旧渠函数为新段代管状态。 |

## 7. 镜头与需要真实验证的条件

沿用现有玩家跟随、手动平移与“回到身边”，不承诺已经实现双人自动取景或特殊领路镜头。0.5白盒必须先检查实际领行距离与安全停点：正常跟上时，手机能看见前方许照或最近转弯识别物；落后时已有察看短句说明她在哪里，玩家可正常移动或平移镜头找她。若手机总在追一个画面外的人，先调整规则中的等候距离/候点或缩短该段，不用离屏传送和自动镜头遮掩。

进入兽情停步时，不自动拉近脸部或打开长对白挡住前方；主动交谈沿用真实暂停与现有阅读区。地标与角色姓名仍遵循 `visibleLabels` 的原锚点避让，不能为了在手机塞下三个名字把字挪到路牌外。薄纸上的细记号在近看可读即可，远景不靠把整张桌图放大成 UI 浮层来解释完成。

需要保留的最少证据：桌面与390×844 DPR3各一段真实领路/停步/重新跟上，一次南林真实止步，一次雨棚安放后重访，以及独行落笔→后来共同补笔前后两图。另核对矮窗口的许照/地标与操作栏遮挡；暂停/载入不摆步、不补笔；旧渠纪念、首章桌图、包扎/药筐补救入口仍正确。

这些检查说明状态和画面是否一致，不代表主观趣味或实体手机体验通过。当前仅完成本文，不声称领路、坐垫、纸签或相关自动镜头已经实现。
