# 《山门之外》美术与声音方向

2026-09-09 · 与 [GAME_DESIGN](GAME_DESIGN.md) 一起待用户确认。输入为已认可的Q版倾向、[产品边界](../docs/research/PRODUCT_BRIEF.md)及本次具体玩法候选；没有把未实现画面标为验收通过。

## 视觉主张

`targetFinish`：一段可完整游玩、视听与角色反应统一的网页冒险。白盒只证明操作；正式切片需人物动作、可辨场景与物件状态、术法反馈、声音、归来变化齐全。首版采用**二维手绘场景与动画化Q版人物，固定斜俯视**，立体感来自绘制、遮挡和地面关系，不靠可旋转3D镜头。

世界属小说的修真社会：山道、驿舍、衣袍、布包、木石器具；媒介为清爽的二维动画式绘画，不做泛黄古画或真人材质。人物约三头身，保留成人身份的肩背、动作与意志；陶七稍宽、许照背药篓、玩家长短衣襟清楚。两款玩家形象共用体型尺度与操作轮廓，不照搬原著动漫角色造型。

四条取舍原则：

1. **术法必须连着真实的物。** 手、牵线、木板落点和被改变的路线能在同屏追踪；漫屏粒子、遮挡瞄准的大招不采用。
2. **熟悉来自同一处的变化。** 驿舍的灯、桌、工位始终处于固定位置，回家从物件和站位看出经历；不用每次切换一张新背景替代记忆。
3. **雨中仍能辨路。** 主循环为中高明度灰青山石与暖木，雨线稀疏，威胁靠动作、轮廓和局部对比突出；不叠黑幕、浓雾与小灰字制造严肃感。
4. **可爱来自举止。** 扶灯要踮脚、稳舟要压肩、试环会凑近看；受伤时收手退步，拒绝时转向自己的物件。不开嘲讽表情雨，不把每次受挫做滑稽摔倒。

## 镜头、地理与轮廓

以1280×720 CSS视口为最小完整横屏目标，1440×900作为主要审阅视口。角色常态约画面高的7%–9%，可看清手势和朝向；战斗中玩家、当前对象、最近威胁同时可见。跟随带短缓动，暂停可平移，无自动旋转；不在施术中突然拉远。窗口变窄先重排界面，不把中文无限缩小。

| 层次/场景 | 识别锚点 | 路线与遮挡规则 |
|---|---|---|
| 玩家 | 米白内衫、石青外襟、腰间小引环；脚下细短弧表示朝向 | 与地面有接触影，穿树后树冠局部淡去；不可被树或屋檐完全遮住 |
| 陶七/许照 | 方肩与工具卷／斜背药篓与束袖，灰棕／苔青辅色 | 重要识别靠轮廓和所持物；关系反馈靠靠近、侧身协作、移去候点 |
| 回石驿 | 歪灯架、院中大回石、两张并排工作桌 | 第一焦点是陶七扶灯与玩家伸手；门、桌、工位同屏，屋檐不盖出口 |
| 溪道 | 斜雨棚、浅色踏石、上方突出眺台 | 水线、板、药筐形成三角；上下路由坡面连接，无颜色才能懂的路线 |
| 旧工棚 | 外侧木栅、半开棚顶、台上环具 | 林路遮蔽物稀疏有间隔，进棚后视野变开；取物台不伪装稀有光柱 |
| 石渡 | 主闸高木框、低滩白石、山脊垂绳 | 入口高台能预读主要地形；水转向的路径连续可见，护身前后方向明确 |
| 危险 | 野兽低伏弓背；散修侧肩起手，手前聚一点光 | 起手与投射方向均可见；不靠敌我同色血条、地面满屏红圈区分 |
| 可作用物 | 轻物有可辨提耳/松绑处；可燃物有干草纤维 | 悬停轮廓加短名，按察看可批量显示；普通装饰不伪造同样标识 |

可放物件的地面和碰撞边界必须与画面吻合；倾斜梁和头顶装饰要有可通过的明确空间。不做看似能翻却被无形墙堵住的窄栏杆。

## 功能颜色、光与材质

地面与人物采用柔和明暗，人物深色轮廓在阴影和亮地都要辨出。主色为石青、米白、湿木棕，暖橙只给灯与火；术法的青白与雨水的低饱和灰蓝分开。颜色只是冗余之一：

| 状态 | 颜色与材质 | 非颜色表达 |
|---|---|---|
| 可牵/可落 | 青白细线、浅虚影 | 物名、实线连通、落点轮廓；不可达为断线与阻挡名 |
| 湿物/干物 | 暗湿反光／粗糙亮纤维 | 悬停“湿木板”“干草”；火落湿处有蒸汽且不燃 |
| 护持 | 淡金弧面，不是实心光墙 | 边缘朝外尖角、承击缺口、剩余时限小刻度；背后无遮蔽 |
| 留势 | 对象下小环及逐渐缩短的白刻线 | 剩余秒数按需显、落点虚影；到期先松动，压点以斜线提醒及时离开 |
| 警觉/锁定 | 琥珀→赭红局部标记 | 问号→定向箭头、敌人转身和起手，静音仍可辨 |
| 协作/拒绝 | 不设好感颜色 | 同伴走近接住物、抬手止住、搬走自己的筐，并留一句可回看的回应 |

夜晚只用于归来后远景光色，不在第一版制作低照度战斗。设置含高对比交互轮廓、减少雨线与屏幕运动；静音、高对比或低动效均不能失去危险信号。

## HUD与文本

常驻仅左上体力/灵力、上方一行当前意图、下方三术法与暂停、右上设置/记事入口；中央给世界。没有任务列表、声望条、修为进度、关系图和物品仓库同时围住场景。

术法预览在对象附近显示名称、消耗、不能做的具体原因；有效动作提交后资源才变化。对白进入时人物仍在原站位，底部单层浅纸色阅读区，主文与当前选项同屏，通常2–4行文字。正文目标18px，设置可增大到22px；增大时拆短句/翻页，不盖住当前选项。不用花体书法承载操作说明。

简中字体优先稳定覆盖的系统中文无衬线，标题可使用有来源记录的宋体。正文左对齐；界面从场景目标读到对象提示再到操作。暂停明确写“已暂停”；记事是玩家已知经历，原作来源和调试状态留在开发文档。

## 动作、反馈与声音

| 动作 | 接收输入 | 生效/落空 | 结束与低动效替代 |
|---|---|---|---|
| 牵引 | 手转向目标、起一段短线 | 物件沿可达轨迹移动，木擦声随落点；阻挡处线绷住，原因文字留下 | 落地轻碰与线回收；低动效缩短尾迹，保留整条关系线 |
| 火焰球 | 扣指与短准备，射线预览 | 一枚小火团；干物短燃、湿物蒸汽、敌人后仰分别表达 | 不震全屏；被打断则收手，资源依实际提交结算 |
| 护身 | 掌朝方向，弧面由近向外展开 | 投射碰弧碎散，命中缺口表明屏障已耗尽 | 边缘淡去；低动效直接轮廓切换，朝向仍保留 |
| 取环/试用 | 玩家拿起自己旧系绳上的环 | 环跟手势转动，陶七松开试架，看物是否稳住 | 不播抽卡稀有度；新用法在同屏旧试架上立刻可试 |
| 受击/败退 | 来向和命中点 | 缩肩失衡、体力少一格，短局部亮边 | 0体力冻结停留，失败原因与两种恢复入口；不制造复活剧情 |
| 回家 | 玩家亲自走进院门 | 熟悉的灯与碗先出现，随后发现车/背架、风铃、人物位置变化 | 无胜利分数遮住生活；玩家放环或摊图后出现简短收束与继续按钮 |

界面开关约0.15秒，施术以玩法时限为准；镜头移动和弹窗不得吞输入。快速点击只提交一个明确动作；跳过对白仅跳展示，仍一次性结算已选择的事实。减少运动时取消屏幕震动和长缓动，保留动作因果。

声音由近及远分层：先是脚步、木器、衣料和水；随后术法的轻鸣、火的短促爆裂与护符脆响；危急起手声优先于背景音乐。院中有低声炉火与疏落拨弦，外景以水、林风为主，渡口加短节奏，归来回到相同旋律的放松版本。音乐不能持续压满全部路段。

首版不做全配音，不模仿动漫演员；每个关键声音都有文字或画面替代。首次用户交互后启声，声音/音乐分别可调与静音，浏览器阻止播放时仍能完整操作。

## 各模式的招牌时刻

| 实际界面/模式 | 输入前 → 玩家动作 → 输入后 | 焦点、压力与声音 |
|---|---|---|
| 标题/继续 | 院门外静景 → 开始/继续 → 同一院子可走；已有存档回实际保存处 | 标题不挡灯和桌；先清楚说明继续哪一份档 |
| 探索与同路 | 雨棚下水滴落在导水板 → 先移药筐再借板 → 许照接住筐，你踏上新路 | 牵线、空出的脚步落点、人物接物构成焦点；水与木声同步变化 |
| 暂停战术 | 散修起手、同伴在后 → 暂停预览护持朝向 → 恢复后挡住一击，让出下一步 | 冻结火光仍显示方向，画面只叠小“已暂停”；护符一声脆响区别失效 |
| 对话/共同生活 | 陶七扶着试架 → 玩家说“松手，我再试一次”并施术 → 陶七松手、物仍短暂停着 | 人物手势与器物为焦点；对白不替玩家执行试术 |
| 成长/行囊 | 两路短说明与现场试台 → 选路并亲试 → 相同旧物出现不同作用 | 无满屏树状技能；窗内只显示当前引环，关页直接回试台 |
| 高压渡口 | 低滩被水隔开、散修占干地 → 玩家护持转位并牵闸 → 水线改道、低滩露出 | 地理变化比粒子更醒目，镜头同时保留泄水槽与同伴安全点 |
| 失败/恢复 | 侧面命中 → 冻结并读原因 → 重试或回安全点 | 保留来向、护持朝向和落点；失败框不抹掉学习依据 |
| 记事/存档/设置 | 想查看共同经历或保存 → 打开轻面板 → 回原暂停状态 | 显示已知事实、保存结果；设置预览文字大小和危险轮廓，静音无需二级菜单 |
| 归来/结果 | 院前曾停着车 → 亲自回驿 → 车已进院或门后多了山脊路标 | 同一机位与物件位置承担结果；灯下放环收束，没有排行分数 |

## 资产边界与未验证风险

必需：两款玩家形象（共享动作集）、两核心NPC、两类威胁轮廓；四处场景及其少量状态；轻物/干湿物/闸/引环；移动、施术、受击、接物与拒绝动作；中文界面和四类核心声音。来源为原创制作或明确可用素材，记录来源及许可，不嵌入小说全文或复制动漫素材。

可降级：长对白立绘可用近景同角色半身；远山动画可静置；水面复杂反射可用流线与明暗；音乐可以少量主题变奏。不可降级：真实移动、牵引与落点、危险朝向、同伴行动、引环两种动作和返驿物件变化。

本轮未生成目标图，没有实际画面证明Q版比例与斜俯视阅读效果。批准后先在白盒机位上制作一张雨棚场景目标画面，核对人物、物件、水线、HUD四层可读，再扩同切片资产；这是既定方向的制作验证，不再发起全新风格投票。实际画面偏离本文或需改变平台/主要镜头时才回报设计变更。
