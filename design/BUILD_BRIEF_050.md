# 0.5 制作简报 · 许照带一段回程

目标平台：沿用浏览器 Phaser + TypeScript，桌面键鼠与触屏；生产延展，不重启原型或换引擎。

依据：COMPANION_050.md、COMPANION_050_IMPLEMENTATION.md、ART_COMPANION_050.md。用户已授权持续自主制作、测试、里程碑推送和公网试玩部署。

本候选只增加一个有界玩法：许照主动带工棚回雨棚的一段路，玩家自行跟上，实际兽情或落后会令她停步。北路可不花资源走通，南路允许观察后明确折回。独行、拒绝、先离开和后来再相约均可继续；约定、实际经过、回程完成、雨棚歇脚与归家笔迹分别记实。

复用五张地图、原画、配乐、术法、兽行为与旧任务。新增两处小地标和一张雨棚坐垫；同伴真实移动决定步态，纸签在实际桌面，禁止屏幕白色导航线。存档contentVersion4按旧版本原清单校验后迁移，不补造新见证或丢弃旧资源。

最大风险与闸点：

- 领路仅变成等NPC走路：真实连续段记录双方轨迹、落后等待、模型/墙钟时间，观察手机镜头和点地跟随负担；不靠暂停剪掉走路时间。
- 南路或换路穿墙：实际碰撞和限制道路的寻路逐段验证；无安全路便停步，不复活/移走兽凑结果。
- 切图传送伪造共同成果：结算在切图前，仅接受双方真实分岔与出口位置；先走只留个人实走历史。
- 新任务覆盖旧任务：约定阶段保留旧修器/采叶目标，旧拒绝和补救入口继续；独行启动不要求NPC回到起点。

已建立模型、纯规则、旧档与边界测试。浏览器主线需桌面及390×844 DPR3实际输入完成出发、同行、出口、坐垫、回家、重开；旧五图回归按完整发行矩阵顺序执行。PASS只证明所测运行事实，手感、自然游玩时长、实体Mac/Safari和手机仍须玩家反馈。
