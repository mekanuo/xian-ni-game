# 技术建议与阶段交付边界

2026-09-09 · 本文件是完整设计候选的技术附件，待用户一次确认；不是已执行的实现计划。

## 推荐落地方式

采用 TypeScript + Phaser，静态网页运行，二维斜俯视绘制；游戏场景负责实际移动、选物、碰撞、对象与角色状态，普通网页层承载易读的中文菜单、对话和设置。选择理由是本切片需要二维空间行动及浏览器交互，不需要自由旋转三维世界。Phaser 官方说明支持 JavaScript/TypeScript、WebGL/Canvas，定位为二维网页框架；这是技术适配依据，不是本作兼容性已经验证。[Phaser 官方介绍](https://docs.phaser.io/phaser/getting-started/what-is-phaser)

比较后不采用的方案：直接写 Canvas 小引擎会多承担寻路、碰撞、场景管理与输入维护；Godot Web可以实现，但本切片没有必须借其编辑器或3D能力解决的风险。官方 Web 导出文档要求 WebAssembly/WebGL 2，并记录 Safari 的部分限制；单线程可减少多线程部署条件，不能笼统说 Godot 不能做网页或 Mac 游戏。这些取舍是结合本切片作出的判断。[Godot 官方 Web 导出文档](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html)

正式实施时核对并固定依赖版本与锁文件，不沿用旧演示的浮动依赖。目标交付为用户直接打开链接试玩的静态构建，同时提供本地启动方式；无游戏服务器、云端模型、账户、付费服务和必须安装的客户端。代码推送按现有明确授权执行，部署使用仓库现有可用静态托管条件；涉及新增付费或账户权限才另行处理。

Mac Chrome和Safari为优先目标，首版横屏键鼠/触控板；不预先承诺手机触屏。以交付时实际记录的浏览器版本核验。开发机Linux浏览器证据只能证明该环境；Mac验证项保留为真实Mac试玩，不能用WebKit模拟冒称已测Safari。若一个浏览器失效，要定位修复或明确报告，不暗中改为必须安装。

## 状态与模块边界

| 边界 | 职责与依赖 |
|---|---|
| 世界规则 | 裁决可达位置、物件、施术消耗、对手感知与时间；只有此处能提交动作结果 |
| 场景与输入 | 把鼠标/键盘转换为明确意图；渲染规则已裁决的位置与事件；寻路不能偷偷穿越危险 |
| 人物与故事 | 读取已发生事件、在场/知情与当前意愿，提出协作或回应；不能凭台词将未开闸判为已开 |
| 界面与声音 | 读取真实状态表现提示、对话、动作与音效；打开面板进入相同暂停规则，不另算结果 |
| 存档与重放 | 保存内容版本、世界时钟、物件、投射物、待执行动作、资源、人物知识和事件；恢复相同局面；拒绝不兼容版本并保留原档 |

实时世界使用固定逻辑步长，表现按显示帧刷新，确保高低帧率不改变留势时限与移动结果。此项为设计建议，具体文件、数据结构与测试脚本在批准后的实施计划中确定。

处理边界：无效目标在提交前不扣费；执行途中真正被打断按已发生消耗保留；没有路径就停下并指出阻碍；资源加载失败给出重试入口；音频失败不阻断游戏；保存失败明确提示和导出入口，不能显示虚假“已保存”。读档不重复发奖、不凭记录重播扣费。

## 阶段与Git推送

当前工作从用户指定的 `bf4d922` 新建 `docs/return-stone-design` 文档分支，保留交接分支与master。设计确认前不替换演示、不生成正式工程。后续开发使用独立实施分支承接批准文档；每个完成阶段及时提交并推送，反馈分别写本地提交、远端成功和未完成验证。途中必要的小修可形成更小检查点，不将“等全部做完”作为推迟推送理由。

| 阶段 | 可审阅产物/完成依据 | 此时不能声称 |
|---|---|---|
| D0 完整设计候选（本轮） | 玩法、来源、美术、技术建议与一页审阅；文档链接/范围核对；提交并核对远端SHA | 用户已经批准详细规格；已有试玩包 |
| M1 空间白盒 | 灯架、溪道、试环、缩减渡口与回驿；实际移动/暂停/术法；两种不同方法；一次受挫恢复与人物回响；可启动构建 | 美术已完成，或操作测试说明有趣 |
| M2 完整流程 | 补全四处场景、六处境、两背景/心愿、两成长、NPC互动、两种地理结果、保存恢复；代表路径证据 | Mac已实测或最终资产已齐全 |
| M3 同切片视听 | 按白盒机位完成角色与环境、功能反馈、声音和中文排版，替代临时资产；不扩下一卷 | 截图能证明完整输入与主观体验 |
| M4 可试玩交付与修正 | 静态试玩入口、构建版本、实际启动/操作/结局/重开证据、已测环境与已知限制；接用户试玩反馈定位修正 | 未经用户试玩就宣布沉浸、有趣或角色讨喜 |

M1先解决最危险问题。若仍像固定机关题或人物只是附带文本，先修改同一切片并推送修正，不越过问题扩建。M2/M3可在边界清楚时局部交错，但完成状态分开记录。

验证按变化范围：文档只查链接、措辞、分支、敏感内容和规则自洽；规则改动测能影响结果的状态转换；输入/镜头改动用浏览器实际操作；集成里程碑再覆盖完整路径、至少两种结果、失败恢复和存档。Linux与用户Mac的证据分开保存。无意义的镜像实现测试和反复全套重跑不作为进度。
