# 0.3：驿中的手艺与下一次同行

2026-09-10 · **范围已获实施授权，规则、美术与存档已集成，正在实机验证；尚未发布。**

用户授权代理在约定范围决定详细设计并实施。用户没有逐字确认本文件所有工序、坐标、接口和参数。本版据此把原草案收为两项一次性短委托、两件有限实用奖励，继续使用已有四图；0.2.2 场景修订独立交付。新增名称、普通器具、对白及用途属于本作原创改编，不宣称是《仙逆》原著事实。

实施计划：[2026-09-09-life-030.md](../docs/superpowers/plans/2026-09-09-life-030.md)。资料仍用既有研究，不重做全书解析。

## 体验与范围

玩家完成首章、亲自在桌边放环或摊图之后，用已有术法帮熟人做好两件小事：修稳一枚挂扣；沿旧路采回两类叶片。各有接取、空间操作、实际结果、返驿交还；顺序自由，也可同时接取。预计每项 5–10 分钟只是关卡预算，正式时长以试玩为准，不用等待或重复刷取凑时长。

- 只用 home、creek、workshop、crossing 四幅现有地图，不增加新区域。
- 保留体力上限 4、灵力上限 6、两份伤药及原有静息规则，不增加经验、境界、货币、商店、日常或随机词条。
- 保留长牵 500 世界单位、普通牵引 300 世界单位、留势 8 秒与额外 1 格灵力。
- 两委托各只结算一次；压扣仅一枚，避兽药囊只发两份。
- 所有新增计时由模型 tick 推进，暂停、对话、菜单和失焦冻结。
- schema 保持 1，revision 保持 return-stone-v1，增加 contentVersion: 2；旧档与嵌套 checkpoint 同时迁移。
- 不新增 NPC 专用动作状态机；许照仅按真实同行、位置与关系回应，不记录未发生的共同采摘。

收敛决定：修器保留“留势后压柄”和“先拨机械止挡”两条完整办法，取消草案中陶七自动走位压柄；采药保留本人护符挡石和东侧安全绕行，取消许照自动剪叶。原有稳舟、同行、避险和关系补救保持。压扣只支持工位试件与眺台倾梁，不再增加与现有掩体功能重复的挡板固定点。药囊在行囊选择后放于本人脚边，免去一套新投掷瞄准。

## 进入时机与真实经历

入口条件为 `flags.endingWish === 'stay' || flags.endingWish === 'travel'`；原 `ended` 表示已经完成首章结局，不清空它以伪造续章。原游戏继续按钮恢复控制后仍能 tick，这一行为保留。仅有 returned、route、ringTrained 或刚到院中不算完成首章。

完成档在回石驿自然获得两个近处话题：陶七“修一枚备用挂扣”；许照“给晒架添两束叶”。不强弹任务板。未通关档补齐隐藏的新实体与默认状态，仍只显示首章目标。原存档的结局弹窗可以按既有方式关闭，不反复弹出。

若药筐仍受潮，许照仍拒绝同行；她可以给辨叶说明，玩家能独自采叶。新委托不偷偷清除 herbsWet、companion 或原关系事实。完成两项后目标为“手艺与行囊已经备好；可继续试术，或在桌边歇一歇”，不虚构 0.4 出口。

## 委托一：把挂扣修到能承重

接取：home 陶七。制作：workshop 固定炉座、活动钳口、压柄。交还：home 陶七或修器工位。物主始终是陶七；玩家不获取通用金属材料。

| 工序 | 必须发生的玩家动作 | 模型结果与反馈 |
|---|---|---|
| 接取 | 近处明确接受修挂扣 | repair.stage=active；行囊记一件歪口挂扣；重复接受不复制 |
| 松胶 | 靠近炉座装好挂扣，再用一发真实火球命中引火芯 | softened=true；短暂火芯和胶软光泽，耗 1 格灵力；擦过、被遮挡和点别物不算 |
| 校直 | 引力术把钳口沿横向导轨从 (1360,570) 拉至 (1420,570) | 实体连续运动 60 单位，到位容差 12；未软胶不能移动，不用对话代替校直 |
| 压紧 | 先留势再走近压柄；或先拨止挡、拉到位后松手再压柄 | 手空、到位且受到留势/止挡支承才夹紧；按实际动作记录 hold 或 stop |
| 试压 | 松开术法后再次近身操作压柄 | 1 秒真实压柄行程，需保持近处且钳口夹紧；完成 tested=true、stage=ready |
| 交还 | 回 home 交还已通过试压的挂扣 | 同一步 stage=complete、clamp=bag；只发一枚压扣，工位呈现修直挂扣 |

机械止挡是原地固定工具，两种背景都能使用，不是提前发放的随身压扣。药铺背景多一句受力说明，修器背景多一句熟悉旧修痕；背景不免除必要工序。

钳口未夹紧、没有留势或止挡时，以 100 单位/秒回原位；重新拉即可，不永久报废。提前松手、离场、移动打断试压不消耗唯一任务物。松胶、已夹紧及已试压结果保留；转图取消未完试压并复位未夹紧钳口。零灵力可走旧工棚静息点，休息不重发报酬。

### 一枚随身压扣

文案：“普通铁木压扣。把物件拉到有固定眼的承托处，近身扣稳，就能松开引力术。只有一枚，可原地取回。”

唯一位置为 unowned / bag / home / lookout，不能同时出现在行囊与两个固定眼。home 交还即得奖，随后工位提供可选、无伤试扣说明，不强制消费或重新领取。试件在 (990,500)，承托眼在 (1030,500)；先牵移、放到承托处，再近身扣稳与取回。

creek 的眺台侧托在 (970,290)，承接倾梁目标 (980,285)，容差 24。安装必须本人距固定眼小于 96、路径无遮挡、手空或正在留势、目标到位。安装后倾梁不能再被牵走，松手与留势到期不关闭支撑；此时可以腾手施术、开回程梯。它不悬停任意空地物体。

取回眺台压扣先检查玩家和当前许照是否位于倾梁原回落包围盒附近：以原倾梁中心 (1080,290)、半宽 18、半高 50，再加 25 安全距离。有人占位就拒绝，不扣夹具；无人时梁回原位置、clamp=bag。platformReturn 或 platformLong 已有事实继续保证通路；没有永久退路时只关闭原入口，固定眼在西侧可达处，不把人关在台内。工位试件取回后留在承托台，不伤人。

## 委托二：留根采叶，给下次行路备一包

接取：home 许照。采摘：creek 两个固定叶簇。交付：home 晒药架。没有随机掉落、毒草猜谜或拔根惩罚。

| 叶簇 | 世界位置 | 实际方法 |
|---|---|---|
| 向阳叶 | (1420,270)，眺台右下石边 | 用已有长牵梯或留势倾梁进入，先放回程梯；不盖原采药记号 |
| 背阴叶 | (1380,680)，落石窄段边 | 朝上护符真正拦下一次现有落石后在间隔中采；或沿东侧干路至 (1455,680)，从窄带之外伸手采 |

两簇均 w32/h28、非 solid。未接时不发光、不入袋；接取后近处察看能看到剪叶说明。采摘使用现有近身 interact，2 秒俯身动作，只剪上部叶，原根仍在。有效移动超过 4 单位、实际受伤、施术或转图取消当前动作，不损失叶片；暂停冻结。采过的叶不能通过休息或转图刷新。

安全绕路必须实测： (1455,680) 距背阴草 75，在现有落石触发区 x1340..1430 外；仍须原 canInteract/clearLine 判定通过。同行记录只在实际完成采摘时检查许照同图距离小于 150、companion=following 且 herbsWet=false。许照留在棚下或拒绝同行时只写玩家独自辨路；不新增“共同挡石/她剪叶”的假事件。

带回两束后，在晒架依次选择“向阳叶放上层”或“放下层”、“背阴叶放上层”或“放下层”。正确组合为向阳上层、背阴下层。每束在 bag / upper / lower 中唯一占位，允许取回和改层，不消耗唯一材料。两层不能叠两束；交换需先取回对应一束。正确摆放后出现“请许照收好路用药囊”，近身交付原子完成 harvest.stage=complete，sachets=2；叶片作为晒架批次装饰留存，不回到可采状态。

### 两份避兽药囊

文案：“许照配好的普通草叶药囊。拆开放在脚边，气味令附近山兽绕行八秒；对人和落石无效。共两份，用完不再补发。”不把任务叶片或药囊用作治疗。

只在仍有山兽的 workshop 使用；行囊按钮写“放一份在脚边”。关闭行囊后经 `act({type:'use-sachet'})` 执行：若玩家原先手动暂停，只保留一个待执行动作，恢复时重新检查场景、数量、脚边可达、无遮挡和当前已有气味。取消待执行不耗份数。

有效落地扣一份，life_scent 实体出现在本人脚边，持续 8 秒，半径 150；同时最多一处气味，尚未过期时第二次使用拒绝且不消费。优先驱离范围内未退走山兽，包括 idle/searching，不能因为它尚未发现玩家而无效果；不伤害、不永久驯服、不改变散修。用原 moveBody/free 避让，不越过岩壁。期满隐藏布囊，敌人恢复原察觉规则；不刷新已退走敌人。

计时沿现有模型“仅当前图模拟”规则：离开 workshop 后气味计时冻结，回来继续消耗剩余秒数；布囊不跟玩家传送。行囊说明显示正在原地点起效。两份全交玩家，不强制先烧掉一份才算任务完成。QA 以首章避战、两只山兽仍在的完成局验证真正用途。

## 呈现与名称

新增道具沿用 0.2.2 原画尺度与贴地锚点；近处标签不盖炉芯、钳口刻线或草叶，任务提示纳入现有可收起“察看周围”。工位增加固定眼、试件与修好挂扣；晒架只增加叶片层与批次签，不另开装修大厅。奖励时各一条声音和记事，禁止用连续弹窗替代过程。

用户曾不理解“引环”。本次对外统一为“控物环”，第一次说明“控物环（旧称引环）：辅助引力术的普通法器；长牵拉得更远，留势停住八秒以腾手”。内部 ring、ringOwned、ringStyle、历史事件及旧存档键保持；不全局替换研究或原著文字。仅更新运行文案、新默认实体名及新事件；旧事件保留当时文本。

## 状态、保存与失败合同

新 GameState 顶层 `contentVersion: 2`、`life: LifeState`；阶段、工序、计时、奖励属于模型事实，UI 不以自己的弹窗状态判断完成。具体类型与九件实体见实施计划。

旧档没有 contentVersion，必须恰好包含 SCENES 既有实体白名单才视作版本 1。先验证原有结构、ID 唯一性、位置和进度，再补入明确的新实体；不靠“数量少了就自动补”接纳损坏档。版本 2 必须具有完整新实体集及合法 LifeState；未知版本、未知 ID、重复 ID、缺旧物、非法数量/安装状态拒绝。

旧 checkpoint 是 JSON 字符串，真实生成时内部 checkpoint=null。外层和这一层快照分别验证、迁移，之后同为 contentVersion 2；递归快照、无法解析、超 2 MB 或非法实体拒绝。读取不能自动领奖、播新任务事件或把首章未完成档变为续章完成。

存档包括半程钳口坐标、留势剩余时长、软胶/夹紧/试压、两束叶所在层、采摘/试压剩余进程、压扣唯一位置、药囊数量和起效剩余时长。恢复后先保留暂停状态，通过既有 UI 明确提示继续；模型 restore 不为读档推进计时。

retry 沿原 checkpoint 完整回退：任务、物品、报酬、世界位置一起退，不能保留奖励却重回领奖前。retreat 沿原规则保留已经结算的物件、任务和报酬，取消即时采摘/试压/未固定牵物，重置未夹紧钳口，保留安装中的压扣与支撑一致。重新开始生成全新 life，不污染手动旧档。

## 验收与交付

1. 原首章主渡/山脊仍各真实完成、归家、重开；未通关的新档不受续章提示或碰撞干扰。
2. 两种背景都可做完两委托；修器至少覆盖留势与机械止挡、未松胶/未对齐/未试压拒绝、提前放手可重做。
3. 两叶各采一次；东侧零灵力安全采摘、护符实际挡石后采摘、采摘中移动/受伤/暂停有正确结果；真实在场才有同行回读。
4. 交还与分拣只奖一次；错层可取回；压扣工位/眺台可装可取，不能双装、不能撤支撑砸到人；药囊真正驱离活兽、无伤害且八秒后恢复。
5. 旧未完成/主渡完成/山脊完成档及旧 checkpoint 可载入；各关键工序保存恢复一致，恶意重复/未知实体与非法 LifeState 拒绝。
6. 桌面鼠标/WASD和手机触控各完成关键工序；新原画实机检查贴地、遮挡、字牌和暂停表现。Chrome仿真不称真机测过。
7. 每个可验证里程碑及时提交并推送源码分支；最终 `npm run verify`、新增生活真实路线、构建与公网文件核验通过后发布 0.3.0。未部署不宣称上线。
