# 0.7 小集北口接旧渠：生产前连接审查

2026-09-11。仅在 `market-070` 工作树做接点研究。依据 [ADVENTURE_070](ADVENTURE_070.md)、[MARKET_070_GEOMETRY_REVIEW](MARKET_070_GEOMETRY_REVIEW.md) 及当前真实旧渠代码；小集白盒尚未浏览器验证，本稿不批准生产，也不把候选坐标写成已建成捷径。没有修改既有设计、地图、存档、测试或资产。

建议优先保留“北口接旧渠北侧高岸”的候选。它可以把石渡彼岸、小集、旧渠与石驿连成一个实际环路，且在旧渠端不依赖分水、截水、药囊或压扣。北口原地景观点只能提供停留内容，不能解决现有同点返回缺少连接用途的问题，不作为本轮首选。

视线是有方向和来源的：首选两点对东南采样来向 **(1220,660)** 的 LOS 均被 L 墙挡住；对初始散修脚点 **(850,560)**，玩家 LOS 仍为true，同行为false。因此只能称北口一处能退开的落点，不能称全向安全区、保证已迁移敌人永远看不见、或自动给予保护。实体人物外轮廓、牌字与墙顶画面仍待正式素材和实际视口检查。

本轮只以 `esbuild write:false` 在内存加载当前 market-model/真实 simulationPorts，读取 free/LOS 并做有限点采样；未运行 tick、浏览器、测试或生产换图，不写运行源码或夹具。

## 可实际行走的旧渠路线

从新落点进出新牌：

`(990,350) → (1100,370)`，站稳后明确互动。反向仍沿这段南侧空地退开，不能点牌面后的岩岸当道路。

接永久西岸并走回原回驿出口：

`(990,350) → (880,400) → (560,400) → (500,570) → (580,650) → (580,900) → (580,950) → (500,980) → (380,980) → (350,1000) → (350,1030) → (310,1090)`。

最后一点距原回驿牌约82.5，可按原出口规则点击回驿；本次模型探测只行走到这里，没有实际互动或切图。沿途不操作水尺、筛框、石槽或邵禾，不把“经过取水处”计成验水。

若压扣仍装在截水架，可从新落点另走：

`(990,350) → (1090,380) → (1150,380) → (1150,410)`。

终点距固定眼80，仍要近身交互、腾手，确认玩家和跟随者均不在渠底，再实际选择取扣。没有取得压扣、压扣在背包或装于别处时，这条高岸路同样存在；新连接不会赠扣，也不会归还远处器具。

反向去小集可从旧驿原入口沿上述西岸样例倒走到北岸，再接新牌。因此它同时服务两种具体目的：从石渡彼岸经小集回驿，避免必须原路再过石渡；从旧渠北岸返去小集与石渡彼岸，或去小集前顺路取回仍装在截水架的压扣。这里只证明新拓扑和接点用途，没有比较耗时、危险总量或宣布必然更短。

## 旧状态不能被新出口越权提交

- 小集入口沿当前0.7合同在认路并归驿记录后开放，独行认路也可，不额外要求与许照共同回程。该进度本来承接已完成旧渠，不在接点研究中擅自提前开放。四水态和未接任务的探测只是独立几何/越权边界，不代表目前正常剧情能跳过前置进入小集；无论来源，换图都不得自动接信或完成渠务。
- `blocked / diverted / stopped / flowing` 四水况均保留。切离旧渠继续执行原 `release`、`canalBeforeExit`：中断工序，水板按已有支持关系收稳，清除离图来水过渡；已清筛框、已装压扣不被抹掉，离图不推进流时。禁止借换图自动清框、复水、验水、报告或添图。
- 留势截水需要真实计时；离图松手会使未扣住的截水板依原规则回槽。这是原退出后果，不是新出口把水态统一设为安全。安装压扣的止水状态则保持。
- 山兽原位、受惊、寻路、已退开和药囊状态分别保持，不因从新口到达而复活或清敌。当前模型对弯道外玩家会撤去该兽的攻击意图并归巢；这是现有地域规则。本候选全程在弯道外，不能扩大成旧渠全图无威胁或小集散修也受此保护。
- 许照 `waiting / refused / sheltered` 等既有关系不因换图变为跟随；原位不挪。通用换图只在已经 `following` 时将目标图许照放到玩家 (+45,+40)，本候选对应 **(1035,390)**，已核对可站且不落水。之后仍由 `canalCompanionTarget` 和真实寻路择高岸；本稿未重放跟随者全程，不承诺自动镜头、共同小集穿行或同行全程无阻。
- `sharedInspect/sharedVerify` 只能由旧任务的实际近身操作与同伴位置产生，不能由“二人从小集回来”补写。小集是否保留可见同行者属于生产人物接入合同，不能把换图的 (+45,+40) 放置本身写成她亲历小集。
- 当前换入旧渠会沿用首个可见静息点更新 `lastSafe`；这是旧渠原有静息点，不能额外开放检修台坐垫。回驿时已有首章 `route` 可能触发原返回处理；新连接不得代填 `route/gateOpen/ridgeOpen/returned` 作为解锁或过关捷径。
- 白盒的 `trip.exitRoutes/completed/returned` 目前只描述同图端点确认和步行折返。正式跨图须另落实何时提交真实小集走法、从旧渠回到北口怎样继续一次往返、何时向桌边实际报告；不能仅把现有白盒“北口已确认”直接当作跨图完成或回驿陈述。
