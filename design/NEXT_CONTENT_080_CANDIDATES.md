### 三条共同体验支柱

| 支柱 | 可观察现象 | 失败现象 |
|---|---|---|
| 我的做法有具体因果 | 改站位、行动顺序或承诺范围，实际试验、人物工作或对手应对随之改变 | 换对白仍执行同一动画、同一结果 |
| 人有自己的事和认识边界 | 对方完成自己的试验／工作／练习，能拒绝越界要求，只评价亲见或明确收到的说明 | NPC 等我领取任务，或者隔墙知道所有事实 |
| 熟练带来从容与可再参与的局面 | 已认识的规律用于第二次不同安排；少提示也能做成一件事，失败可主动收手 | 重复读字、绕远、花资源才能推进；只有痛苦取舍，没有办成事的快意 |

## 2. 概念 A：试火之前——我愿为哪一种说法作证

**主类型：** 空间试验与有限见证；`experienceProfile: hybrid`。取走实际弹道和遮挡，证词就成为阅读题；取走人物目的与见证范围，试验只剩练靶。

原创晒纸场经营者罗婶正在考虑让年轻散修简禾在场边演示用火。简禾想接下一场小型示范，却把“在这面石壁前可控”说得过宽；罗婶想保住自己正在用的工作面，不愿凭一句“修士自有分寸”同意。玩家来此不是判谁撒谎，而是决定自己愿意协助检验到什么程度、为哪一条实际结果作证。二人都不是恶人，也不等玩家救命。

- **核心动词（5）：** 察看来向、约定试法、就位试验、邀请复验、限定说明。走位、三术法和近身交涉仍是操作，术法不自动给证词添正确性。
- **循环：** 听到一个具体主张 → 看现场是否支持 → 提出一个有限试法并亲自就位 → 观察实际首撞／余火／见证位置 → 据此保留、缩小或再检验主张。再试必须改变来向或见证关系，不能重复刷确认。
- **压力：** 对方急于把局部本事说成更广的保证；玩家想帮一件事办成，却不应替未试过的范围背书。压力来自行动与说法之间的差距，不加倒计时逼答。
- **失败：** 试验越过约定边界、损坏明确的试片，或把遮挡后的未知说成亲见。损坏保持真事实；可以停手、承认局限、提出更窄试验，不逼玩家烧毁正式货物才有故事。
- **世界响应：** 罗婶实际保留原工作台，或把本次工作移到已经共同看清的背墙工作面；简禾实际改变下一次发射站位，或收起尚不能成立的示范安排。不是开门、给休息位、加声望。玩家能够回来参与这场按新边界进行的短示范，而非只多一张完成纸。

**player_job：** 作为有基础术法、也要为说法负责的第三人，把一次容易说大的演示变成可检验的约定。

**recurring_job_loop：** 主张 → 实际站位／来向 → 一次可收手的试验 → 对照各人所见 → 下一次安排。最多两轮关键试验，第二轮必须读第一轮留下的实物与认识。

**signature_command：** `N/A`。有限选项“只试正面”“换到另一侧再看”“这边我没看见”及真实站位足够；不用自由文本扮演法官。

**resistance_chain：** 简禾愿意示范但不愿无限耗法 → 罗婶不能同时看见墙两侧且不接受凭空保证 → 改站位能补见证，却会改变哪一面需要保护 → 事后双方只承认各自亲见及玩家明确说明的部分。人物拒绝的是具体条件，不检查隐藏好感值。

**advancement_ladder：** 先看懂一次来向和石壁首撞 → 用另一侧及另一位见证者提出有效复验 → 自己组织一场范围清楚、双方愿参与的短示范。成长是获得可用的质证与安排能力，不是获得地方裁决权。

**原作张力的亲手表达：** 玩家能施术，却不能由“我做到了”推出“别人可以放心”。观察、改假设与许诺／实成分离沿 SOURCE_BIBLE 的 adaptable 结构；不同人的愿意与允许不能被成功动画吞掉。

**招牌画面：** 石壁一端的光焰实际止住，另一端的试片仍保留未测状态；罗婶站在自己看得见的那一侧，简禾移到重新约好的发射位置，玩家决定这次站在哪里。视觉不靠证据面板替代现场。

**最小验证切片：** 一小块试场、固定石壁、两处明确的廉价试片／安全承接面、两位有名人物、两轮有限安排；不新增箱子拼摆。先测试“相同物理结果，但见证人被墙挡住／实际在场”的区别，再检验玩家能否通过真实复验改变下一次安排。材料不是外出收集品，不无限补发。

**零资源合同与能力增量：** 玩家零灵力时可以负责站位、观察与邀见，简禾在自己同意的两次有限演示内施术；玩家不借他的施法补充自身资源。玩家愿用自己的火或护符可承担一个实际环节，不能替代另一侧见证。NPC 的约定发射及试验对象响应是**待实现的新局部规则**，并非目前敌方射弹已能完整支持；不允许借此开泛用指令伙伴。未能同意第二次试验时，如实收束为局部结论并保留再次安排的可能，不补全局保证。

**最大风险：** 玩家是否真的有“用行动限定说法”的因果权，而不是按顺序点两个实验按钮。

**否决观察：** 只走到所有标记再点“如实说明”就稳定得到所有人的同意；或两轮只有重复挡弹；或必须靠长篇审讯、隐瞒未提示的信息才制造差异。任何一项成立，停止此案，不添加第三轮、第三人或虚假指控挽救它。

**叙事语法与预算：** 小任务簇汇入一次有限安排；两轮、每轮至多三个明确意图、两位人物、三个结束类型（共同验证局部范围／只完成部分／主动收手）。承诺、本人看见、转述、实际演示保持区别，但不做任意证据排列组合。

## 3. 概念 B：院里两件事——不替别人答应时间

**主类型：** 共同空间中的顺序协商；`experienceProfile: hybrid`。压力来自两个同时成立的工作目标，非事实真假，也非敌我胜負。

原创制纸人柳苓要在晾架下铺下一张湿纸；修灯人卢诚要从同一块作业地面试落灯架。两人有各自工作周期和安全边界，玩家原本只是来请教自己的灯具。他们不要求玩家搬两件东西换奖励，而是愿意各自完成本职，只是不接受玩家同时答应“现在就可以”。

- **核心动词（5）：** 观察准备、约定先后、明确让停、实际协作、重新交代。
- **循环：** 看谁已经开始与占用了哪块地面 → 提议让出一个完整工作窗口 → 本人就位做一个需要的动作 → 另一人的动作因真实空间而继续或等待 → 用剩下的布局安排第二件事。
- **压力与失败：** 口头许诺不等于另一人已腾地；先让某人开工，会暂时排除另一人的当前做法。可重新协商，不能通过读对白冻结后同时交两份“完成”。没有现实长时间等待、材料报废倒计时或两边必损一边的强制道德题。
- **世界响应：** 两人按照实际先后把灯装好、纸铺下，或一人选择保留今日计划稍后再做；完成后的院子具有实际照明／工作占地变化。玩家只记自己参与的环节，不自动获得两人的技术或共同成果。

**player_job：** 带着自己的灯具问题加入一个已经在工作的地方，学会让协作对别人的计划也成立。

**recurring_job_loop：** 察看当前占地 → 有限约定 → 实际参与 → 看对方动作 → 调整另一项安排。

**signature_command：** `N/A`。两个具体人物的有限招呼与停止按钮即可，排班表和自由命令都不需要。

**resistance_chain：** 两种工作实际占地冲突 → 有人不接受半途中断 → 玩家只有一项牵物支撑 → 一事完成后留下的新占地又影响第二事。

**advancement_ladder：** 先完成自己的单项协助 → 知道承诺要等对方真正停下 → 独立安排两事的实际顺序。零灵力必须允许人手完成各自工作，玩家靠让停与站位协助，不把“没有牵术”罚成空等。

**原作张力与招牌画面：** 自己有本事不意味着有权替别人安排；灯落稳之后，制纸人才把湿纸铺进空出的光下。只借合作专长与自主离开结构，不照搬原作人物事件。

**最小切片与最大风险：** 一院、两人、两项工作各一次开始／中断边界／完成；最大风险是它实际仍然只是搬物两次，或先后任意且最终没有差异。

**否决观察：** 点先 A 后 B 就是唯一解，或者二者无论先后均只等待玩家提交；若要靠更多日程、疲劳、库存和随机需求才有意思，也否决。叙事采用主干加瓶颈，只有两种先后和主动止步，不扩经营模拟。

## 4. 概念 C：划线切磋——赢得一手，不压服一个人

**主类型：** 有限规则下的实时对抗；`experienceProfile: system-led`，叙事层解释规则与回读输赢，不冒称两层同等承载。

原创同阶散修闻朔在一小片平地练习逼人失位，愿与玩家各试一回，但不接受烧毁场边器具或倒地后追击。玩家可以选择练“守住自己的退身线”或练“逼对方换位”，不是接战清人后过路。对方想练自己的弱处，发现玩家反复同一招会明确换侧，也能结束本场。

- **核心动词（5）：** 读起手、走位试探、定向护持、施术逼位、主动认输。
- **循环：** 约定本回合空间目标 → 试探对方来向 → 用位移和既有术法改变站位 → 按实际边界／首个有效动作结算 → 换攻守再试。
- **压力与失败：** 对手主动改变角度，玩家必须留退路；越线或错误护持是一回合失败，不是扣到零体力才算输。不得为训练凭空恢复生产灵力，零灵力可选纯步法的守线回合并随时结束。
- **世界响应：** 闻朔实际采用更侧向的第二回合站位，或者根据玩家明确的练习目标不再追逼；输赢保留具体动作，不兑换装备，也不永久变成玩家下属。

**player_job：** 为自己的惯用办法找一个不讨好自己的试手者。

**recurring_job_loop：** 定一个空间目标 → 交手 → 承认实际判定 → 利用上一回合暴露的问题换攻守。

**signature_command：** `N/A`。动作和有限约战选项已足够。

**resistance_chain：** 对手有自己的目标和退路 → 护符侧后暴露 → 牵物与施火的机会成本 → 回合成立还要遵守双方约好的停止条件。

**advancement_ladder：** 保住一条退身线 → 看懂对方侧移 → 在反向站位下主动迫使换位；不发第四术法或伤害倍率。

**原作张力与招牌画面：** 修行不是只挑战更大血条，败一次可以带来新认识；一道护符留住正面，闻朔已经退向侧方，两个人都还有主动止步的空间。

**最小切片与最大风险：** 一个对手、两回合、固定地形和明确边界；最大风险是当前敌人行为并不能支持可信的自愿切磋与结束，加入后的规则又让零灵力步法成为故意放水。

**否决观察：** 站在角落就能等对手自败、胜负仅靠烧掉三格抵抗、零灵力靠受击无敌硬扛，或必须新增近战连段、招式库和复杂学习 AI 才成立。叙事预算只是约定、当回合反馈和重访一句具体回应，不包装长篇师徒线。

## 5. 先硬否决，再做取舍

| 硬门槛 | A：试火之前 | B：院里两件事 | C：划线切磋 |
|---|---|---|---|
| 有 3–5 个可重复手段，改变原因与结果 | 有候选循环；必须排除“点齐证据” | 有动作，但容易退回顺序按钮 | 动作充分；必须排除站角取胜 |
| 原作张力进入行动，低阶身份可信 | 检验、有限认识、他人决定直接影响行动 | 合作与自主性成立，修士特征偏弱 | 认识与修习成立，角色生活承载较少 |
| 不依赖巨量系统或资产 | 两轮试验与有限见证；新增边界需明确 | 若工作真正独立会引出更大调度成本 | 可信对手与停止行为成本较高 |
| 不重复已交付章节 | 从借还／通路转到主张与证据；仍需防复刻试术教程 | **当前否决：与已有徒手工序／单件支撑的重复风险过高，局面质变不足** | 有区别，但比当前敌人加血或训练围栏更难 |
| 玩家保有因果权、结算权 | 可用复验改变安排，不能凭说服按钮实现 | 若修成全自动两项工作，玩家沦为调度按钮 | 空间胜负明确，人物回响不能代替实际对手 |

没有总分。**推荐 A 作为下一次有界设计对象；B 当前淘汰，C 保留但不并行实施。** A 的结构最直接补上“会用术法之后，怎样判断别人据此提出的要求”，也允许善意地把事情办成；它所需的新局部规则比一位完整切磋对手更容易限定。代价是本章不保证给新路、新物或新的伤害能力，必须靠一次实际可参与的示范和人物安排变化证明值得玩。若这一点撑不住，宁可搁置，不给它硬加奖品。

这不是因为 A 的文字更丰富而选择它。首个白盒应把说明压到最少，只看：**相同试验结果，在见证人实际看见／没看见时是否形成不同且合理的下一步；玩家能否用一次真实复验改变这个下一步。** 这就是单一最大风险。

## 6. A 的交接合同

以下五项独立保留，供下一阶段收敛，不直接成为源码字段。

- **player_job：** 有限能力的参与见证者，不是调查官、裁判或救场万能修士。
- **recurring_job_loop：** 提出有限试法 → 真实空间执行 → 对照各人的所见 → 调整一次可执行安排。
- **signature_command：** `N/A`；有限近身选项、移动与三术法足够。
- **resistance_chain：** 施法人的意愿／有限试验次数 → 墙两侧的实际视线 → 约定边界与物理结果 → 人物只按自己获得的信息决定。
