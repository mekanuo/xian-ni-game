### 开放维度与三条支柱

| 开放维度 | A：篱外那件事 | B：帘后留话 | C：火未到梁 |
| --- | --- | --- | --- |
| 玩家责任 | 界定自己究竟能说明什么 | 完成别人明确允许的联系 | 判断先保什么、怎样止住实际危险 |
| 核心循环 | 换观察位、验证、缩小判断 | 询问授权、走近转达、观察对方行动、再决定 | 察看火路、选接近面、处置、复查剩余火源 |
| 压力来源 | 遮挡和不完整证据 | 两个人的目的与知情范围不一致 | 危险发展与可烧物件的实际相邻关系 |
| 空间关系 | 同一物件有互相遮挡的两面 | 公共檐廊与私人帘后相邻但不互通视线 | 火源、传播介质、工作物和取水面构成局部网络 |
| 结果 | 更窄但可靠的说明，或承认不能断言 | 消息收到／见面／拒见各自成立 | 留下哪些实物、哪里仍烫、当下能否使用 |

三条共同支柱：**动作改变原因**（不能只有新增字句）；**人物只知道实际获得的信息**（不是读玩家全局账）；**有限能力仍可办成事或主动退出**（不是没有资源便只能受罚）。每一案都要保留一次失败后可理解的重新判断，不声称重复参加一定有趣。

不新增外部玩法先例。内部参考只借已交付的真实首撞、遮挡、近身、物件不可洗白及暂停连续性；不把“已有这几个基础动作”当作新循环成立的证据。

## A：篱外那件事——看到了搬动，未必看到了拿走

**主类型：** 小范围空间调查；`experienceProfile: narrative-led`。移动与物件察看服务于有限判断，删除情境后不包装成独立解谜系统。

原创纸坊主人余槿发现一架纸张被人从院内挪到篱外，认为有人趁她离开搬走了东西。隔壁修篱的成茂承认挪过架子，却只愿解释自己做过的一步：原位置会被自己正在修的篱片压到。他还没来得及看纸架背面的情况。玩家并非办案者，两人也没有必须被揭穿的恶人身份。

候选现场只有一个纸架、遮住背面的篱片和一段受潮痕。玩家可以绕到背面确认纸尚在不在、近身察看仍被压住的下层、请求当事人先停下手中工作，或用实际轻物操作露出遮蔽处。玩家移动纸架也会改变原先可见的受潮关系，不能移动后仍声称亲眼看见它原来如何摆放。

- **核心动词：** 换位、察看、有限追问、挪开遮物、限定说明。
- **循环：** 听一个具体说法 → 找到其观察盲处 → 做一次会保留或改变现场的行动 → 区分原先看到与后来推断 → 让当事人按可信范围处理自己的物件。
- **压力与失败：** 急于给出完整解释会跨过证据范围；先搬物可能失去原位证据。无法查清可直接说明，不能硬判偷窃或扣好感逼玩家重来。
- **世界响应：** 余槿可以按实际纸张状况继续晾纸或转移损坏部分；成茂是否继续压向原工作面取决于现场是否真已清空。不是“交证据开门”，也不新增赔偿货币。
- **player_job：** 一个愿意看清再开口的旁人，不是拥有神识的侦查官。
- **recurring_job_loop：** 对照一个说法与一个观察面，必要时调整一次现场，再说明自己知道的范围。
- **signature_command：** `N/A`；有限近身选项足够。
- **resistance_chain：** 单面观察 → 操作会改变现场 → 两人各自只见一段 → 玩家无权强迫双方接受完整推断。
- **advancement_ladder：** 能指出缺少哪一面 → 会先观察再挪物 → 能不依赖全套线索作出足够窄的处置。
- **招牌画面：** 帘外看似空了一半的纸架，玩家绕到篱后，剩下的纸还被压在阴面；另一人仍站在自己看不见的位置。

**最小切片／最大风险：** 一处局部现场、两人、两观察面，只有一个争议。最大风险是它仍只是绕两个点拿两句说明，物件操作并不改变判断。

**叙事预算：** 任务簇只含两个可交换观察点，最后汇入一次有限说明；两位人物各保留“本人知道／不知道”的必要回应，不为每种走位另写分支。不存在第二宗案件、跨图取证或无限追问。

**最小反例闸口：** 对照“先看背面再挪架”和“先挪架再观察”；若最后所有可说内容和纸坊实际处置完全相同，否决。只增加一条“你碰过现场”的旁白不算差别。若有意义差别只能靠新增随机线索、推理 UI 或更多证人，拒绝扩张。

**当前意见：暂存，不优先。** 它与 0.8 之前暂存的试验／见证提案仍有“取证后获得认可”的结构风险；不能因为换掉火球就自动认为解决了原问题。零灵力、无破坏的完整说明应可成立，但尚未证明足够空间参与量。

## B：帘后留话——替人传话，不替人答应见面

**主类型：** 有限交涉与空间中的知情边界；`experienceProfile: hybrid`。若去掉谁能看见谁，选择退化为对白；若去掉人的目的，躲避视线也没有需要承担的后果。

原创离山者程蕙借一间工棚整顿自己的去向，不愿现在见以前的同门魏迟，却愿收家里托他带来的一句消息。魏迟需要确认消息确实送到，也希望问她是否一起走；他不是奉命抓人，拒见不触发敌对。二人都不由玩家调度人生。

一处檐廊有公开交谈处、帘后本人所在的小间和能从侧面看进来的缺口。玩家可以先在帘后问清允许转达什么，走到檐下说明“她收到了，但今天不见”，或获得许可后约双方自己走近。魏迟只沿一段明确可见的檐廊寻找合适交谈位置，不巡遍整图；他真的从缺口看见程蕙时，得知人在这里的事实不能被后续对白擦除。玩家不搬箱子封住视线，不控制她站哪，不用术法胁迫见面。

- **核心动词：** 近身询问、选择通行侧、转达限定内容、招呼、主动停止居间。
- **循环：** 获得一条有限授权 → 选择从哪边接近另一个人 → 传达并观察他的真实行动 → 回到授权者说明实际发生了什么 → 决定结束传话或允许一次会面。
- **压力与失败：** 传话与暴露所在不是同一事；把对方带到缺口再说“没告诉他”并不能抹掉亲见。也不能为制造压力让魏迟无理由突然冲进私人空间。
- **世界响应：** 只收到消息、双方真的近身交谈、已被看见但仍拒见分别保留；魏迟收起待传消息或在公共处等待，程蕙仍可独自离开话题。没有增加名望、永久随从或新通行权。
- **player_job：** 受有限委托的中间人，不是替两个人和好的裁判。
- **recurring_job_loop：** 问清许可 → 实际往返传达 → 回读对方已经做出的动作 → 缩小或结束下一步。
- **signature_command：** `N/A`；两三项具体许可即可，无自由文本命令。
- **resistance_chain：** 收消息不等于愿见面 → 行走可能暴露可见信息 → 已见事实不可撤销 → 会面还需本人同意。
- **advancement_ladder：** 准确传一句话 → 注意自己带来的视线变化 → 完成一次不扩大授权的联系。
- **招牌画面：** 玩家站在檐柱外把话说完，帘后的程蕙仍未走出；魏迟收起信纸，路还在，关系却没有被一句“任务完成”强行解决。

**最小切片／最大风险：** 两人、一个视觉缺口、一次有限传话；没有追踪城镇、身份伪装或自主生活模拟。最大风险是正常玩家只需照着对白顺序点两次，所谓隐私空间没有决策，反而强迫人多走几步。

**叙事预算：** 主干加瓶颈，限“授权—转达—回告”三节点；只收到、见面、已见但拒见三种结局处境。中间的空间事实不因汇流删除，但不延伸成新的派系支线或下一轮传话。

**最小反例闸口：** 在相同授权下对照公共侧传话与带对方经过真实缺口；必须只有实际看见才产生所在已知，且“已看见／未答应会面”能共存。若两个方向最终都自动见面，或为了让选择重要必须安排恶意跟踪者、秘密数值、无提示倒计时，否决。零灵力应能完整传话和退出；不以牵物或护符购买人的隐私。

**当前意见：保留。** 它能延展离山者各自去留与有限协作，但目前最大的空间差别仍可能只形成一个旗标。先不把它包装为主线章节；若将来只适合短人物事件，应如实缩小身份，不能靠扩大场地填时长。

## C：火未到梁——先灭源头，还是先隔开正在烧的草帘

**主类型：** 有限局部险情处置；`experienceProfile: system-led`。叙事说明为何值得保护及为何有人不肯马上丢掉器物，主要决策由实际火源、物件与接近路线承担。

原创篾匠沈岑在偏棚熏干竹篾，翻倒的炭盆已经点着一截地面草帘。玩家到来时不是接“杀三只怪”的委托，而是看见一件仍可处理的事故。沈岑愿意停熏，却要保住架上这一批已经编好的篾胚；她明确先撤到取水面，不让玩家指挥她留在火里干活，也不把她当等着被护送的受困者。

候选只含一处炭火源、一条会连接火势的可移动草帘、一架篾胚和一处固定水桶。**不是全图火灾模拟。** 能否移动草帘取决于尚未着火的实际部分/时点；已经燃烧的整件不能突然被牵起洗成普通物件，沿现有“燃烧屏不可牵”的原则。更稳的候选是火先到草帘一端之前存在清楚的撤帘窗口，过了窗口就放弃牵动，改走另一侧取水灭源。精确火势关系尚待白盒，不把任何秒数当已验证平衡。

- **核心动词：** 看火路、换接近面、移走未燃物、取水泼浇、复查止火。
- **循环：** 辨认火从哪儿来、下一件会受影响什么 → 选择先截断物件联系或先接近源头 → 真实移动/泼浇 → 观察还活着的火和留下的烫处 → 调整最后一步并确认篾架能否继续使用。
- **两种候选手段：** 早到且愿意耗灵力时，用既有牵物从侧面移走尚未燃的草帘，保留靠近篾架的一面；这只隔开传播，不自动灭炭。零灵力时，可从取水面实际提桶靠近炭盆，先灭源；已经烧坏的草帘保留损坏，不能把用水说成完好修复。徒手搬未燃草帘也应是合法候选，必须真实到近身面；不能为了卖术法故意拒绝人手。
- **压力与失败：** 火没有等玩家看完所有面才变化，但看菜单/对白/手动暂停仍遵守正常冻结。迟到可能失去保帘或保篾胚的机会，不应锁死出口或在不可见处连续伤人。允许承认只能保住工作架、让损坏保持，或停止救物实际退出。
- **世界响应：** 炭盆已灭／仍有火、草帘烧毁／被移开、篾胚完好／受损各自独立。沈岑只在安全后走近检查她要继续使用的工作架；全保或止损改变现场实际剩下的工作物，不给一件无用途纪念品当成果，也不追加“帮她再跑一趟材料”的新任务。
- **player_job：** 有基础控物本事、仍要看火路的现场帮手，不是无所不能的灭火修士。
- **recurring_job_loop：** 看一段真实危险联系 → 处理一个物件或源头 → 回看剩余联系 → 决定下一步或止损。
- **signature_command：** `N/A`；近身取水与瞄准实物，不做调度界面。
- **resistance_chain：** 源头仍燃 → 未燃物可能变为不可移 → 灭源不等于修复损坏 → 主人只在实际安全后恢复工作。
- **advancement_ladder：** 认出源头与传播介质不同 → 用自己的接近面选择处置先后 → 在较晚到达时承认已失去的办法，保住仍能保的对象。不是从一种火球升级为更大火球。
- **招牌画面：** 草帘已被挪离架脚，隔出的空地上仍有炭光；玩家从另一面提水走近，篾匠在安全处看着那架真正留下来的篾胚。

**最小切片／最大风险：** 最大风险只有一个：**火源与可燃物的实际空间联系，是否真的让两种先后有不同的用途，而不是一条固定的“点水桶—点火盆”流程。** 白盒不先造全棚资产、不加烟雾视线、风向、气候、温度条、人物恐慌、可燃属性通用系统或联网。

**最小反例闸口：** 同一初态，直接点最终救火对象并让默认寻路执行；若这就不看火路而稳定保住全部东西，且移动草帘从未改变可走面或实际受损对象，本案否决。反过来，若晚到后只剩必损且没有可调整一步，也不是选择。不得靠增加伤害或隐藏倒计时伪造必要性。

**当前意见：推荐优先收敛一次风险合同，尚不批准白盒。** 代价是需要一个新但有限的环境因果，复用现有物件状态本身不会自动让它成立。它比 A/B 更直接把下一段主要行动从认可、许可和一手输赢转向处理一个持续发展的现实局面；若这个有限因果做不小，则停止，而不是改成新的训练场。

## 硬否决结果与推荐取舍

| 硬门槛 | A | B | C |
| --- | --- | --- | --- |
| 不只是既定对白继续或通行按钮 | 尚待证明；最易退成线索齐全 | 尚待证明；最易退成两趟传话 | 候选有源头/物件结果，须排除固定点击序列 |
| 至少 3–5 个有用参与手段 | 名义具备，实际用途是最大疑点 | 具备，但不能把走路次数算策略 | 具备，徒手与牵物不能只差距离数字 |
| 原作张力进入行动 | 有限认识与说法责任 | 去留、授权与他人意愿 | 有限力量、止损与具体补救；术法不替代常识 |

**玩家因果权：** 移走的必须是当时真实未燃的物件；被移开的物件不能再沿原位置把火传过去。水要实际泼到当前火源才灭源，不能按“取过水”发完成。直接用零资源去灭源、先隔帘再灭源、晚到止损应至少保留两个不同且合理的实际现场。
