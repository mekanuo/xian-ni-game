# 0.9 山外出行：先兑现谁的愿望

2026-09-12。独立选题诊断；0.8 仍在整轮验收，本文不宣称已发行。0.9 A/B/C 均未批准，C 继续暂存，不修改或挽救该案。没有运行模型、浏览器，没有制作美术、设计精确地形或批准白盒、生产。

**结论：下一段应兑现玩家自己的一次山外寻访，而不是再接一件驿周杂务。现有材料能支持这个制作目的，却还不能支持一份可靠的新章节方案。** 最欠缺的不是第九张地图，而是“到了环网之外，我要亲手做哪件与自己的修行有关的事”。在这点落实前，不推荐给任何新案排生产。

沿 game-concept 的硬否决、因果权、结算权和最小反例方法；本任务限定至多两个体验目标，因此不重新生成三套总游戏概念，不覆盖既定概念。

- 已锁：原创凝气三层修士；石驿熟人及自己的桌边；实时二维空间、现有输入和三手段；已认可画质；实际资源、近身、碰撞与暂停；王林的身份、经历和功绩不转交。
- 本次开放：一趟出门的私人目的、环网外目的地承担的实际作用、陌生人怎样按自己的事务回应、玩家何时认为已经走够。
- 不开放：境界跃升、货币经营、第四术法、远征负重、饥饿宿营、昼夜期限、宗门通行证系统；也不以练场成绩作为旅行资格。

## 实际地图说明了什么

静态核对 [`content.ts`](../src/game/content.ts)、[`canal-content.ts`](../src/game/canal-content.ts)、[`kiln-content.ts`](../src/game/kiln-content.ts)、[`market-content.ts`](../src/game/market-content.ts)、[`spar-content.ts`](../src/game/spar-content.ts)，并核对 model 的场景切换及 market 的入口门槛。这里只说明现有连接，不冒称各条当前存档路线均已实走。

| 当前空间 | 实际连接／用途 | 对“走出去”的限度 |
| --- | --- | --- |
| 回石驿、溪道、旧工棚 | 驿↔溪道↔工棚；工棚取自己的环与回程同行 | 建立起点、能力和熟路，尚不是山外新生活 |
| 石渡 | 溪道↔石渡；低滩与山脊是玩家真实出行经历 | 首版已经完成过渡，不能把同一彼岸再当首次突破 |
| 雾岭旧渠、背墙旧窑 | 驿↔旧渠；溪道↔旧窑↔旧渠 | 增强熟悉区域的连通与借还后果 |
| 小集 | 石渡↔小集↔旧渠 | 确实形成有用途的新环路，但北口已经是旧渠，不能改名为山外出口 |
| 驿后练场 | 驿↔练场 | 自愿试本领的近旁支路，不是主线门禁 |

地图数量增长与离开熟悉圈不是同一事实。现有网络的远侧仍接回已知地区；没有一个当前可玩的环外目的地。只把新地图另一端接旧渠或驿后、换一块远地路牌，会重复已经交付的收益。

拓扑上，未来新方向应从既有外缘引出一条可双向回走的支线，到达环网之外的真实目的地；**不是删掉现有小集北口、收回已有捷径，或强制单向转场。** 单图可以容纳途中局面和目的地，无须同时许诺一座城与第二张远景图。具体接点、尺度、旧路线门槛和入口安全性仍待另外核对，本文不指定假精确坐标。

## 目标一：我自己决定走多远，并带着实际本钱抵达或折返

**必要的玩家承诺：**“我为了自己的修行去寻访一个陌生去处；途中可以避开争夺、动用本领或提前回头。抵达不是交任务，回头也不会把已发生的事洗掉。”

这只是一趟有界出行，不是远征模拟。最小内容是一处可预见的途中阻力、一段实际返程、一个抵达后仍可操作的目的地。出发理由需同时容纳两种已确认心愿：想留下的人也会外出寻找合适的修行办法与往来；想远行的人也仍可把石驿当归处。不改玩家心愿，不强派许照陪行或重演她领路。

### 已有行动如何产生不同结果

可复用已经成立的移动、察看、轻物声响、视线、火球、定向护持及敌人退出；不要求新地图发明第四种危险。区别应来自**同一初态里，玩家为了这趟自己的行程改变了什么**，而不是分别造“有钱路线”“穷人路线”。

| 同一途中局面的实际做法 | 可成立的因果与结果 | 不能冒称的结果 |
| --- | --- | --- |
| 看清遮蔽与来向，避开对方的争夺面 | 保存灵力抵达；未退场的对手和原占用面保留，回程还须应对实际局面 | 不能因为过了出口，就标记对方离开或整条路安全 |
| 在可见范围用轻物落声改变对方站位，再从原先受看守的一侧通过 | 声音实际发生、对方实际移动、玩家趁空走过；声响不能无限重放，回程读取新的真实位置 | 不能把“使用过引力术”当作路已通，也不能跨图继续替玩家演完引敌 |
| 定向护持后换位，或以实际命中使对手退出 | 有真实消耗、伤势或退出结果；如果确实处理了此处对手，返程这一处的条件相应改变 | 不能把耗灵力本身当更勇敢；不能强迫受伤证明参与 |
| 在资源、站位或对方动作不利时退出 | 带着本次已发生的消耗和局面返回，目的地仍未到达；以后可再试 | 不能给未到达的人补抵达记号，也不能用正常离图伪装重试刷新 |

上述只指出现有规则能承担的差别，不保证未知几何已经具备它们。一次看懂后直接点地安全通过是合理熟练表现；反例针对的是**直接点终点在所有局面都支配其他做法**，不能故意关闭寻路或追加隐形伏击救案。

“必须由原创凝气修士参与”不是世界里只有他能走这条路。必要性来自这是他要走的一趟路、资源是他的本钱、控物和护持实际扩大他的选择；不能靠凡人突然不会挪脚、同阶人物无理由旁观来突出玩家。零灵力仍必须有可判断的步行退路；是否能零灵力抵达尚须具体局面证明，不能只凭本表承诺全路线安全。若主要差别删去术法后只是多走几十秒，这个阻力不值得占章节篇幅。

### 最小反例与停止线

1. 同一合法初态，直点目的地、主动换面、动用一项已有本领三种行为，若现场和往返条件除了 MP 数字全相同，否决该途中布局，不补更多敌人。
2. 抵达出口后立刻返回：若未处理的威胁自动消失、取走的轻物复位、损耗被免费清掉，则没有兑现实际出行。正常重试／败退可以沿既有快照合同，但不能与普通折返混同。
3. 若必须全清敌人、递交物件或听完陌生人委托才能前往目的地，又回到了许可式帮工链；删掉这道门禁仍须有玩家自己的动机。
4. 若所谓远方只是入口—敌人—出口，抵达没有可做之事，**目标一单独不足以组成下一章**。这正是当前尚未解决的缺口。

## 目标二：抵达后，我亲自判断这里是否值得成为我的去处

这不是另开一个制作案，而是目标一必须交出的目的地内容。**“可达”应转成“对我有用，但未必归我所有”。** 取得入口、得到一句欢迎、获得休息许可，均不足以完成这个转换。

目的地应容纳一项由玩家主动发起、与自己的修行有关的实践：使用现有本领，在陌生人的真实生活边界中试出一个自己愿意继续使用的办法或空间。到场的人不是等玩家救火、送信、修棚；他们有自己的用途，能继续做事，也可以拒绝让出自己的物件。玩家不需要代表恒岳、夺取洞府或赢一手证明值得进门。

**但现有输入没有提供一个足够扎实的具体对象与行为。** 不能把下面三种填空直接升格为方案：

| 看似能填上的内容 | 此刻为何不成立 |
| --- | --- |
| 山下同阶修士再示范／约一手 | 0.8 已有自主来向与一手结果；换师傅和地点不足以产生新目的 |
| 替主人处理事故，换一张坐垫或棚角 | 重复旧窑借还便利或暂存 C 的帮工报酬，不是玩家自发修行 |
| 找到无人石室，点一下变为自己的修行处 | 空间若不改变实际使用，只有一句产权和静息按钮；若靠灵气增益、新练功数值撑起作用，又超出当前范围 |

因而此目标目前**未通过概念硬门槛**：缺少可重复、有用途的参与手段，也没有说明角色能动性如何进入目的地的实际结果。不能用“去镇里看看”“遇到更强修士”“以后学新功法”这类未来承诺补齐。

下次有具体对象时，只需回答一个局部问题：同一到达初态，玩家实际换站位、施术或停止介入，能否让一处自己在乎的使用条件不同，同时不让陌生人失去意志？例如能用但不独占、暂且不适合而主动保留退路，应当由实际对象与人的行为造成，不能预置两句结局。若无法给出这组因果，就继续判否，不先造镇景。

## 最小交接结论

- `player_job`：为自己的修行寻找去处的原创凝气修士，不是沿路领取杂务的帮工，也没有对别人居所的裁决权。
- `recurring_job_loop`：备行并选择自己的目标 → 判断一段真实行路条件 → 以已有本领通过或折返 → 在目的地亲自试用／了解一项具体条件 → 带着实际经历决定返回与再访。目的地一步目前尚未找到可靠内容，不能删成到达按钮。
- `signature_command`：N/A；沿用实际行走、瞄准、近身和有限对白。
- `resistance_chain`：熟悉路数进入陌生处境 → 消耗与站位限制本次选择 → 抵达不等于得到所有权或他人协作 → 未完成的愿望仍由玩家决定如何继续。
- `advancement_ladder`：从走熟驿周路线，迈向能自己筹划一次抵达与返程；再把一个陌生地方变成有具体用途的可再访去处。不是境界、地图数或已帮助人数增长。

内部玩法先例只复用旧窑的真实空间后果、小集的人物意愿和练场的施术可读性；不复制它们的借屏、开门、领奖或约战闭环，不另做外部先例研究。图像、声音、精确坐标、存档版本与 QA 矩阵均不在这次诊断里预填。

**建议给根代理的决定：保留这两项体验目标，尚不立项 0.9。** 下一次选题只需补出一个真正值得玩家亲手前往的目的地实践，并用上述反例反查途中是否为它服务；若补不出，明确没有可靠方向，比把另一环形地图包装成山外出行更符合已确认承诺。0.8 的完整验收与发行不受本文阻塞或范围扩张。
