# 山外短暂结伴：一发与一段路白盒合同

2026-09-12。**仅供根代理审阅的有界白盒设计，不批准正式第九章或实施。** 0.8 R4 保持独立冻结。本稿未运行模型、浏览器或构建；以下坐标、余量和路径全部是待证候选。

按 game-world-design 的动作—变化—反例方法收敛；沿用 [已批准空间冒险与角色扮演方向](GAME_DESIGN.md)、[产品边界](../docs/research/PRODUCT_BRIEF.md)、[来源范围](SOURCE_SCOPE.md)及 [SOURCE_BIBLE 设计入口](../docs/research/analysis/SOURCE_BIBLE.md#设计阅读入口：全书结构与边界)。现有 GAME_DESIGN 已锁定概念方向，本次不另造 CONCEPT。局部承诺来自 [出行诊断](OUTBOUND_090_PLAYER_PROMISE.md)，目的地不必另设可重复机关的修正以 [短暂结伴审查](OUTBOUND_090_SHARED_CROSSING_REVIEW.md) 为准。

## 唯一体验假设与停止线

玩家为自己寻访山外去处，暂与一名同阶行路者商量，各自选择站位。对方只承担一发；玩家看见真实弹道和对手动作变化，决定接着走、自己施术，或退回。**投入与通过是两件事；另一人出手不会替玩家完成道路。**

只问：预备好站位的普通玩家，能否利用这一发造成的真实交战变化？核心动词为观察、商量、换位、施术、走或退。短循环到一次实际过路或折返结束；目的地只保留可步入的眺望面、一个可读的具体发现和短暂去留谈话。成长体现读懂他人的有限投入，不产生修为、好感或通关奖赏。

首个廉价否决是**拒绝结伴后直接点彼岸**。如果同一初态及实际扰动后的代表局面，都能以近似耗时、伤势、资源和返路条件随意直达，则这一发只是装饰，停止该布局。合法熟练直达本身不算错误，也不关闭寻路来救设计。

## 一次公开初态

一个独立灰盒场景，不导入生产档，不接正式旧地图；西端仅标“回熟路”，东端标“望见山下”。正式外缘接点另审，不能把现有小集北口改名。重开才重置整个公开初态，普通折返与再交谈不重置任何资源或实体。

| 参与者／物 | 固定初态与边界 |
| --- | --- |
| 玩家 | 原创凝气三层，HP 4、MP 6，既有三手段，无在途弹、护持、牵物或预存起手。零资源对照唯一差异为 MP 0；不是游玩中把灵力写成零 |
| 行路者“岑舟”（暂名，原创） | HP 3、MP 1；同阶，自愿共担一发而非永久伙伴。初始未同意同行、未起手、未发射。选择、取消和绕行都不补 MP；没有隐形第二发 |
| 路口散修 | 既有 raider 行为，HP 3、idle、无预装起手与射弹；一发命中只到 HP 2。沿用既有警觉、追击和发射节拍，不降低伤害／速度来凑通过 |
| 敌方 MP 的真实边界 | 现行 raider **没有 MP 计量或逐发耗灵力**，不能虚标“MP 6”再暗中无限射，也不能让等待耗空敌人制造放行。首白盒明确沿用此有限实现，不新增敌方资源系统 |
| 空间 | 两块固定岩背、一处短露面、可步行返回的西侧掩护、彼岸观察面；无门、可燃桥、清场奖励、隐藏倒计时和随机事件。无 RNG |

岑舟要到彼岸看山下路势，再决定从哪面下山；不是为玩家等待的代打者。开场说明：“我也要去那边。我能出一发，你先看好落脚处；打偏了，就各自退。”选项只需“这一段同行”“我自己走”“先回去”。拒绝后他不免费替玩家打路，也不敌对；他暂不愿独自硬闯，可在岩背自行观察，不声明已经抵达。

## 第一块几何候选：用于推翻，不作为已成立关卡

坐标单位沿用现行世界；候选范围 1400×1000。两块实岩分别为矩形 `(360,300,220,300)`、`(760,300,220,300)`，其余地面正常可走；外围只设可见边界。玩家 `(480,660)`，岑舟 `(520,660)`，敌人 `(670,380)`。西返端 `(260,760)`，彼岸观察面 `(1100,700)`。

- 预备脚点约 `(550,640)`，彼岸岩背脚点约 `(790,640)`，两者间实际露面跨度待射线核对。岑舟最多选择 `(610,640)` 或 `(730,640)` 两个出手候点；必须从自己脚下实际走到，不因玩家到站而出现。
- 出手后先退回西岩背，再决定是否仍有安全的真实步行去处；不要求他按时冲过去。若尚未共同抵达，彼岸只出现玩家个人发现，不能提前摆放他的谈话实体。
- 两块岩背下方保留绕行空间，退出不需要火球、牵物或同行许可。候选退路为西侧岩背沿外缘回西端；必须用真实点击与键盘各走一次，检查敌人追近后的寻路拒绝，不以初态“地面可走”保证随时无伤。
- 构建首步须检查完整身体、40 单位导航网格、射弹初始偏移、可见射线与手机投影。上述点若落障碍、需贴极限边角或候点互相穿人，应先否决或只调整几何；不改全局碰撞和寻路。

**这块几何有明确的失败可能：敌人首次发现存在警觉和起手延迟，短露面可能本来就能直接走过。** 必须先跑直达／独行控制，再投入友方反馈；若控制结果使协作没有实际用途，本稿不授权补第二敌人、强制初始开火或封闭下面的退路。此时交回“不值得继续”的结果即可。

## 同意、真实出手与退出

| 当前条件 + 行动 | 真实效果与玩家读法 |
| --- | --- |
| 安全近身商量并同意 | 只形成一次同行承诺；尚未耗 MP、未命中、未过路。对话冻结现场，关闭后岑舟才走向当前可达且可见敌人的候点 |
| 玩家先选自己的预备面；岑舟到达合法候点且亲眼见敌 | 岑舟按自身位置与退身通路决定起手；看不到敌人或自己的退身面受阻就暂缓，能看到被哪块岩遮住。玩家不需要在命中后突然寻找出口 |
| 开始准备火球 | 扣岑舟的 1 MP，准备 0.5 秒；显示朝向与聚光，目标是当时实际看见的敌人位置。发出前再次检查遮挡／目标是否仍可见；不成立就收手，灵力不退还，不重新免费起手 |
| 真正发射 | 仅一发，420 速度、0.92 秒寿命，使用实际发射位置及 24 单位偏移所经过的首撞；瞄准点不追踪身体。出手时一句“我出手了”只报告行为，不保证命中或通行 |
| 火球命中仍在争夺的敌人 | 按既有一格伤害、起手归零、0.6 秒 alert；敌人仍 HP 2、能继续追击。只有这个真实碰撞可产生打断，撞墙／落空不能写入替代窗口 |
| 玩家说“先不同行了”或实际退回西端 | 撤销未开始的行动；准备中取消则保留已扣 MP。已发出的弹继续；岑舟实走退向岩背。重复交谈不重新给一发 |
| 岑舟受伤或自己的退路被敌人逼近 | 停止未发起手，优先实走自保；受伤真实扣 HP，同一来袭不逐帧多扣。受阻就原地显示受阻，不瞬移、无敌或替他清敌。HP 0 只结为本次失败，不虚写安全退走或永久死亡 |

同意不是出手开关后面的定时播放。岑舟只作“选两个候点之一—看得见才准备—一发—实走自保”的有限判断；不增加学习 AI、全局伙伴命令或最优战斗规划。玩家独行不锁主要目的地内容；玩家可以用现有火球实际让敌人退出，但这种结果不能替代“友方一发形成窗口”的正面证据。

## 窗口预算与来袭归属

已有规则的纸面上界：命中后敌人约 0.6 秒 alert，再积累 2 秒攻击，持续可见时最早约 **2.6 秒后重新发射**。这不是保底安全时间：之前已发出的弹保留，敌人可以移动，玩家可以走到另一个危险来向。不能画固定倒数条或在这段时间屏蔽受击。

正面路径应允许玩家在起手前已经看清彼岸脚点，命中反馈后约 **1 秒正常决策／输入间隙**再出发，仍能利用真实恢复间隔；暴露段目标为约 1–1.2 秒实际步行。两者相加约 2–2.2 秒，仅是与 2.6 秒比较的候选预算，须由实际身体路径和已有余弹检验，不能当作已证明的 0.4 秒安全余量。若必须读取内部发射帧、提前埋指令或亚秒反应，停止此布局，不延长敌人硬直来挽救。

以下是**必须新增的局部技术能力**，现有代码并不具备完整友方战斗：

- 射弹要能区分玩家、此行路者、敌人，并保留真实射者身份。射者不撞自己；同行双方互相挡住弹道则熄灭／散开、不造成友伤，不能一概穿过友方身体。墙与实体按最近真实接触，精确同点优先遮挡；发射偏移也参加判断。
- 路口这名敌人可实际感知玩家或岑舟：只在真实可见范围选择目标，现目标仍可见时保持；丢失后只能沿已知位置寻找，重新看见才切换。命中让他认识射弹来向，不隔墙赠送玩家坐标。现有 `enemyTick` 只读取玩家，不能直接宣称已经支持。
- 敌弹锁定的是**发射时目标位置**，随后按首撞伤害实际遇到的玩家／岑舟，不跟踪目标；玩家护符只按真实方向和前缘截弹，不能给岑舟远程罩一层免伤。无需把“替他挡弹”另立验收主线。
- 岑舟火球不能直接伪装成 `owner='player'`：现有命中逻辑会回读玩家位置，既有 enemy 分支也只处理玩家／许照。需要局部发射归属、受击对象、目标点参数与岑舟受伤入口；不要求重构全局阵营或修改旧地图敌人策略。

暂停、对白冻结所有准备、行走、资源计时与弹道。取消同行、走到端点不清弹。白盒不做真实跨图，端点仅观察身体到达；普通退出仍让当前现场可继续检查，正式跨图余弹与保存策略不在这次偷定。

## 反馈与有限收束

画面优先让玩家同屏看清自己的预备面、岑舟的聚光、目标和露面末端。手机若需要在短窗口里先拖两次镜头才能点彼岸，即视为该构图失败；可在安全准备阶段普通暂停看路，正面证明的起手至通过段必须实时，不靠暂停消除操作时间。

撞墙用墙面 impact，命中用敌人受击／起手散开；不弹“道路已安全”。玩家逗留时敌人继续警觉、追击、起手，岑舟不会补弹。敌人转向谁须能从朝向和实际移动看出，日志仅作证据补充。

彼岸以可实际走到的两处观察脚点承载同一发现：此前只能听说的山下道路，现能看清它沿河弯向坡外；灰盒用简单轮廓与短观察句，不许诺未制作城镇。岑舟实际到场才可说自己的下一站、与玩家道别；未到者不能隔空评价共同过路。玩家可多看一会儿或沿真实来路返回，均不回血、不领物、不登记永久伙伴。这里的地点与人物均为 open；有限协作、试探、改变条件与各有去处沿已有 adaptable 结构，不移交王林事件、能力或日期。

## 最小证伪与交付

采用上面一份公开初态，先判断空间，再验证真实一发；每次重开完整记录初态，不能在途中写 HP、MP、坐标、目标、命中或通过状态。允许明确标注的最小碰撞边界实验，与完整游玩证据分开。

| 必须观察的对照 | 可接受的具体证据／否决条件 |
| --- | --- |
| 独行直接点彼岸；独行主动换面；同意后预备接一发 | 记录实际路径、敌人发现／起手／发射／受击、双方 HP/MP 与抵达。若一发对代表局面没有可读且可利用的改变，否决；不得把“不按推荐走”当失败 |
| 同意后站着等 | 岑舟最多一发、敌人仍活跃、玩家身体未过路。不动也能永久清场或自动送达则否决；短暂观察后再走本身允许 |
| 实际有墙挡在已发弹的路径上／敌人真实离开瞄准点 | 首撞／落空后无伤害、无重置敌人攻击、无按时开窗。可由实际走位造成；若固定局面无法自然复放，单列明确几何边界实验，不注入弹来冒充整条路径 |
| 正常约 1 秒输入间隙后接窗口；保留之前敌方在途弹 | 检查玩家真能用步法或已有护符通过，反应不依赖内部时钟。撞旧弹就如实受伤；不能销毁它取得 PASS |
| 零 MP 拒绝、迟疑或失手后回头 | 从实际走过的位置点地／键盘退回西端，敌人未被清空，保留伤势与岑舟消耗；退出能做，不承诺任意站位无伤 |
| 准备中取消、发出后取消、普通暂停恢复 | 未发／已发严格区分；MP 不退、旧弹续飞；谈话不会偷打，重谈不会补弹 |

正面通过还应立即沿路折返一次，读取当前敌人和双方位置；如果返程被默认恢复初态才成立，说明没有保住本次行程。双人共同抵达只由双方实际脚点判断，先同意或先出手不能替代。

最低状态面只有：承诺是否仍有效、岑舟当前动作与目标点／一次资源消耗、双方实际受击与弹道、各自实际抵达、已看过的观察面。它们仅用于这次内存灰盒及终态读数；不新增正式存档 schema、经验条或“协作已学会”标志。

交付应保留公开初态、实际输入、真实首撞与敌方目标变化、终态及失败反例；静态数值估算不计通过。只在一个有用正面路径与关键反例都成立后，根代理才决定是否继续；仍不是整章、素材或正式发布批准。
