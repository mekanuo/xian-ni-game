# 0.2.1 回石驿场景修订

用户反馈：Mac Mini 打开回石驿，布局奇怪、简陋且丑。本轮沿用已批准的空间冒险与美术方向，先修首章石驿，不开始成长或新章节。

## 实际修订

- 一整座五开间木驿替代两座重复小屋与横向占位围栏；屋檐、木梁、窗棂、石基和局部暖灯形成统一立面。主屋基脚仍对齐原有碰撞。
- 茶桌、工台、药架、木车、开放卧榻与静息长凳使用新原创家具图集；桌上归来地图、共同记号、工台挂环及药材补救仍读取真实状态。
- 新绘平面地景连接廊下铺石、绕石院路和草边；所有人物、器物、障碍与地图出口坐标沿用，不需要存档迁移。地景不含预画的可互动物件。
- 移除回石硬边底色和横贯屏幕的细围栏，围栏仅在庭院边缘形成短段；回石本体保持原有识别锚点。
- 桌面回驿镜头按可用高度适当拉远并向主屋取景，保持人物与归灯操作可见；宽屏自动覆盖地图，避免地图外纯色条。手机继续使用原有近景。
- 地名在细节丰富的屋顶上用小块深色牌面承托，避免文字依赖白色虚影描边。

## 验证范围

权威命令仍为 npm run verify；加入 home-layout-check.mjs，记录1440×900 DPR2、1920×1080、1280×720、1920×500矮窗口与390×844 DPR3首屏，真实鼠标归灯与桌案走近对白，以及矮窗口行走至院中央后人物与操作栏的间距。完整两路结局、重开、触控、存档与战斗保留现有验证。最终结果以 qa/verification.json 和当前证据为准。

这是 Linux Chrome 分辨率/DPR仿真，不能冒称实测用户的Mac Mini或Safari。视觉比对针对真实运行截图；原 quality-review/home-target.png 仍是参考目标，不是本版实机。三张新背景/建筑/家具原画均接入运行包，角色仍为静态原画配合状态动作，不是完整逐帧重制。
