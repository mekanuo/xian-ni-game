# 0.2.2 山道场景精修与路牌

2026-09-09。用户已认可 0.2.1 石驿画面，反馈其他三图粗糙、路牌文字偏离牌面。本次在同一空间与存档规则上补齐实际场景原画。

## 结果规格

- 路牌箭头、木牌和中文文字共用同一布局；文字随字数缩放、按屏幕像素密度绘制，左右出口均无脚下重复名牌。
- 溪道、工棚、石渡分别使用完整平面地景，保留真实地图坐标。水纹按实际水域裁切，岸线用同坐标地景的湿土唇和碎石过渡。
- 雨棚、工棚、绞盘、眺台墙有独立材质原画。雨棚与眺台下墙保持分离，窄墙连续铺设。
- 舟、药筐、导水板、梯、试环块、干草、行囊、路碑、空筐、牵扣、固定桩及静息垫接入原画；可移动对象跟随模型位置/尺寸，烧损与受潮状态仍可见。
- 主渡排水与山脊搭桥只读真实 gateOpen/ridgeOpen；不把桥画进初始地景，不改变碰撞、法术消耗、同行或结局。
- 保持用户认可的石驿镜头、音乐与打击反馈。新增资产失败有可见重载入口。

## 验证与边界

`scripts/region-art-check.mjs` 使用桌面 DPR2 和手机 DPR3，实际行走修舟、护药借板、上路进棚取环训练、返回溪道再到石渡；路牌截图与区域截图在 `qa/evidence/region-*`。完整发行还须运行 `npm run verify` 并核对公网资源。脚本 PASS 仅代表操作与检查条件成立，主观画面质量另行目视审阅。

人物仍为静态原画加运行时动作反馈；没有全套逐帧动画。岸线大尺度遵循既有碰撞形状，未伪造自由河道。Mac 与手机真机实际体验由用户试玩，Linux Chrome/DPR 仿真不能替代。
