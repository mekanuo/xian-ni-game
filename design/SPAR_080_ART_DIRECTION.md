# 驿后练场 · 局部正式美术方向

2026-09-11。依据已收束并获准生产的 [SPAR_080_GAME_DESIGN](SPAR_080_GAME_DESIGN.md)，继承 [ART_DIRECTION](ART_DIRECTION.md) 与 [PRODUCT_BRIEF](../docs/research/PRODUCT_BRIEF.md) 的原创修士、简体中文网页冒险边界。使用 game-art-direction 及其方法整理。本文件只规定练场及其出入、归驿回响，不覆盖全局方向，也不重启画风选择。

`targetFinish`：达到已认可石驿与小集的明亮手绘、成年Q版比例、真实脚点和可辨动作成色。它是一处可主动反复来访的小练场，不是新境界、大型竞技场或评分模式。本文为正式制作方向，尚未生成闻朔或练场资产，未运行正式场景、浏览器、构建或真机验收。

## 五条能否决画面的原则

1. **场地给脚步留白，细节集中在使用处。** 中央圆线、三处来向与绕行路径清楚；围廊、树石只属于外围。不能用大屋顶、石桩、稠密落叶和高草把已测中央空间填满。
2. **手、身体和真实来向一致。** 正面交手时两人相向，左右换位时朝向随实际位置改变。不能让闻朔朝画面右边抬手，却从身体下方发出向南的弹；不能用镜像翻图冒充上下转身。
3. **收手不等于余弹消失。** 停下一次起手、先前术法仍在、这一手真正结清是三个可辨时刻。第一声收手不能触发胜利光、自动对白或返家过门动画。
4. **结果来自眼前发生的事。** 护符展开、实际承击、被碰到、侧身后弹自然结清各有不同反馈；按下按钮不亮成功标记。圈外不画护盾，边线不发光封人。
5. **明亮与质感同时保留。** 地面中高明度、人物深轮廓、少量局部冷暖与材质差异，杜绝泛黄滤镜、大片暗角与全图平均碎纹。最小视口能分辨脚点、来弹、文字与操作，不靠提高音量或满屏震动补救。

时代元素仍是修真社会中的驿舍、石地、衣袍与木石用具；媒介是清爽二维手绘，不是古画复刻或写实摄影。人物理想化为约三头身成年人，不转为幼童大眼或魁梧写实武将。所有闻朔与练场细节为 open 原创，不借原作独有衣饰、法宝、功法名或动漫演员建立身份。

## 场地、光色与使用痕迹

中央是一片有人扫过、常落脚的灰青石地，夹少量浅灰米色补土；暖木短围廊和草边说明它在驿后。顶光柔和，沿用现有上左侧微亮、接地影偏灰绿的材料语言。中央低对比，墙根或外围才有少量潮痕和苔色；没有新水域、台阶捷径或能躲弹的假实心陈设。

使用感来自三类平面痕迹：反复落步处的浅磨面、圈外绕行处断续的扫土痕、外围树下的少量细叶。它们不连成一条亮路，也不预先标出正确躲避方向。避免重演小集首轮“所有地方同一种底纹、建筑像平摆模块”的问题：地面明暗有疏密，木石体量有立面、脚影和朝向，但不能为丰富画面新增中央障碍。

| 已定中央事实 / 外围候选 | 美术约束 |
|---|---|
| 圆心(900,940)，半径70 | 画成直接落在地面的灰米色细粉痕或浅刻痕，连续可辨，不能高起如石槛或变成法阵。使用与真实圆相同的地面坐标，不另压扁成椭圆改变边界。 |
| 身体留17单位余量 | 圆线本身仍表示约定范围。短说明写“站在线内，给脚步留余地”；不再加第二个抢眼内圈让玩家猜哪条才算。脚点和贴地影优先可辨，衣摆跨线不冒充实际越线。 |
| 正面(900,720)、左侧(680,940)、右侧(1120,940) | 以已踩浅的平面站位和一处克制短记号辨识。不是待点亮的三个任务槽；只在约定后用当前提示和闻朔真实站位说明来向。 |
| 圈外四点绕行，南点(900,1160) | 整段可走；石板纹理不伪装挡路边。尤其南点必须容纳脚、衣摆与少量地面，外围栏杆不伸进脚点。 |
| 拟1800×1400全图，入口约(900,1280)、招呼位置(900,980) | 保留正式布局候选性质。进场先看到真实出口、扫净地面与闻朔，再走近了解练习；大树与围廊不把南进场口夹成未经测试的窄道。 |
| 石驿东侧后院连接候选 | 使用独立可辨小门/路牌，与既有“驿后空屋”和去溪道主路区分。正式脚点与碰撞由生产定位核对，原画不先锁死门位。 |

外围建筑要像能使用的驿舍附属空间：木梁有支点、屋面有立面，脚在既有外围障碍上；若某一段没有实心碰撞，就不把它画成胸高栏墙。中央不增加武器架、可牵木桩、可烧草垛或坐垫，避免卖出本活动没有的玩法和免费恢复点。

## 闻朔与两人的相向关系

闻朔是同阶散修，重心稳，动作克制，愿意互试但不是考官。新身份候选为灰紫短外褂、淡米灰交领、石褐绑腿，袖口收紧，束发露出颈肩转向；不戴夸张冠、不背许照药篓、不拿武器或发光法宝。体量与现有玩家、沈砚同级，面部辨识来自眉眼、发式和轮廓，不能仅把占道散修旧帧改色。

闻朔至少能表达招呼/静立、真实行走、抬手起势、放下手并等候。制作时必须有能读出朝向的前侧与背侧依据；左右可以一致镜像，上下不能只翻左右。动作的身体、头、手和术法起点应成为一体，不让一枚浮在空中的光点替人物完成转身。

| 时刻 | 关系与姿态 |
|---|---|
| 初次走近 | 闻朔在实际招呼点略转肩看玩家，手在胸腰间短招呼；玩家靠近后谈，不从远处传音开局。 |
| 约好一侧、正在定位 | 真实脚步沿圈外路线前进，衣襟和重心随实际位移变化；朝向先服务行走。转弯不能把脚滑过圆心。 |
| 玩家挡住定位路线 | 在真实停止点收步，手不继续挥动，短句“先让我过去”；保留人与路的距离，不加敌意红圈。玩家让开后从原点续行。 |
| 双方就位 | 闻朔转向玩家，而玩家脸/手仍服从真实朝向。正面来向时闻朔朝南、玩家可朝北准备，必须看得出相对关系；不强转玩家身体而改变其实际选择。 |
| 起手 | 肩臂先收后抬，手前聚出一处小光，真实发射方向随规则；这不是随意新增的第二次蓄力或更长反应窗。 |
| 主动收手 / 越线 / 首次受伤 | 闻朔在真实脚点降手、重心回稳，不瞬移回招呼位置。已经飞出的术法仍独立留在场内。 |
| 结清后再约 | 不远程弹出“下一轮”。两人仍站在实际位置，玩家走近，闻朔再转肩交谈。资源保留，不用恢复光效暗示自动补满。 |

许照明确在驿里等候，练场不制作或摆放许照、旁观剪影、助战手势或第二份名字。入场前的等候选择用她当时的真实位置和普通短对白表达；返回仍可走近再邀，不以回图动画自动恢复同行。其他位置等待/拒绝者不出现在本场，纸图也不添共同笔迹。

## 镜头与手机构图

自由探索沿现有斜俯视跟随。约定进入定位阶段时，平滑移向以(900,880)为中心的 **600×600世界单位活动构图**；这不是600 CSS像素，也不是新全屏模式。保留相同透视、角色比例与上下朝向，不旋转地图来把左右来向都伪装成“正面”。

定位和一手交手优先保证全身玩家、全身闻朔、圆线与真实来弹在可用视域内。中心范围约为x600–1200、y580–1180，正面人物头部、南侧绕行脚点都占这个范围；姓名应就近避让，不能固定压在南点脚下导致掉出屏幕。不得把已验证的600×600改回过窄高的画幅，或为塞标题把底部裁掉。

| 阶段 | 镜头行为与首焦点 |
|---|---|
| 自由探索 / 南侧进入 | 跟随玩家；先清楚当前落脚、返回牌和可走空间，再让玩家走近闻朔。没有全图海报式缩小。 |
| 约定、绕场定位 | 平移与必要的活动比例调整发生在这一段实际行走中。焦点是闻朔走向哪一边、玩家让出的路；不延长规则起手等待镜头演出。 |
| 已确认、正在一手 | 活动缩放稳定，不突然推脸、拉远或跟火球飞。即使格挡成功也不切慢镜头，不改变下一次真实碰撞时间。 |
| 收手而余弹未清 | **保持当前缩放，开始跟随玩家**。玩家走开时不滞留在空圆线；画面内的余弹按真位置继续显示，短提示仍说明未安全。不承诺无限距离的人与弹始终同屏，也不能因弹离屏就提前结清。主动把镜头拖离后可用既有回身，不用自动强拉与玩家争控制。 |
| 余弹已清 / 结果 | 从实际脚点平滑回探索跟随，恢复近身交谈节奏。结果字不锁屏、不遮仍在场的人物，不使人或弹的位置变化。 |
| 暂停 / 导入中途档 | 人物、起手、弹与姿态相位冻结；不自动播完收势再声称保存一致。主动拖图仍属观察，回身回实际玩家；恢复时接同一阶段和尺度。 |

桌面1440×900、矮窗1280×500、手机390×844至少分别检查。手机先保住上下HUD之间的有效操作区域，目标是看得清约三头身人物的手向与落脚；不能将文字与按钮一同缩成世界小字。600范围的适配必须用扣除HUD后的实际可用宽高，不能凭整屏尺寸宣布南点可见。触屏点选护符方向时，按钮区和读字区不能拦住圆线旁的可点地面。

低动效取消额外镜头震动、长缓动与尘屑摆动；镜头阶段逻辑、真实移动、手向、来弹和余弹跟随保留。相机不能用暗角、运动模糊或放大角色遮掉侧步空间。

## 一手的功能反馈与结果

地面浅灰青、人物深色衣纹，闻朔术法沿既有低饱和暖土光但要与地面拉开明度；护符保留淡金弧面。所有关键区别都同时依赖形状、方向、时序或短句，不靠红绿判断。

| 行为 / 真实事件 | 输入接收与过程 | 实际生效、结束与非颜色冗余 |
|---|---|---|
| 确认来向 | 对白说明“从正面/左侧/右侧来”，闻朔开始真实定位 | 地面记号只提示当前站位；不画从人到人的白线或完整弹道答案。 |
| 玩家点步法落点 | 复用现有克制落点提示与实际迈步 | 脚、身体接地影和圆线构成判断；没有留下的安全幽灵替身。 |
| 闻朔起手 | 前臂抬起、手前短聚光、一次明确的起手音 | 光必须在正确手侧；只在真发射后出现一枚弹，不在存档恢复或暂停时重复出现。 |
| 玩家护符 | 手掌与弧面按真实wardFacing展开 | 单纯出现弧面不弹“挡下”；仅真实block产生朝外碎弧与短脆声，弧面耗去状态仍按模型。 |
| 侧身避过 | 玩家移动，弹沿真实方向经过；没有预先绿色成功框 | 真发射且自然结清、未被碰到与未越线后，才给一句“这一手避开了”。不为站定等空弹消失提供额外胜利演出。 |
| 被碰到 | 接触点短亮、玩家收肩、体力真实减少 | 局部钝响和简短反馈，闻朔停下一次起手。不是打空敌方血条，不画倒地处决。 |
| 踩出线 | 圆线与脚的实际关系继续存在，只给短句“出了线，这手先停” | 不画空气墙、不吸回圆心；边线不闪成护盾，已发弹不消失。 |
| 主动收手且还有余弹 | 闻朔降手，保留一枚原弹与玩家行动 | 短句“收手了，这一发还在”，仍可步法/护符；没有结果对白盖住落点。 |
| 结清与再约 | 手落下、术法散尽、人物恢复平常站姿 | 简短结果与近身再谈入口；不播放全图胜利、加经验或回复资源动画。 |

如首个停止原因是收手/出线，余弹随后碰到玩家，表现应同时保留“先停下”与“随后被碰到”；不把后来的hurt改写为另一场失败，也不因收手而藏去受击。具体“护符朝错方向”等判断必须来自可证明的状态/事件；不能从玩家最后一帧脸向猜过去为什么失败。

护符弧面是朝向提示，不是可承诺到每条像素边的几何尺。不得为好看缩窄既有可挡前半区或承诺精确90度临界；相向手势、弧面开口和实际block的关系应在明确正面/背向案例中成立。玩家主动火球打断方案已否决，练场不制作抢攻成功、击退闻朔或抢先破招反馈。

## HUD、对白、路牌和归驿纸图

沿现有HUD保留体力/灵力、当前一条意图、暂停和必要动作。练场内牵物/火球持续不可用，显示一句明确原因即可，不展示可点的抢攻奖励图；活动中的治疗、静息等也不能借“恢复”动画暗示可用。没有资源初态下拉、练场重开、三方向星级、连胜计分或九格收集面板。

近身对白仍为浅纸色短段落，通常2–4行；当前可选来向用自然中文，选完让出中央画面。定位阻挡、未到位、资源不足、余弹未清只给眼前原因，不把完整合同常驻在顶部。姓名保持“闻朔”，不像白盒以放大姓名代替人物身份。正文沿稳定中文字体，操作说明不使用难辨书法；增加文字尺寸时拆段或翻页，不遮选择。

小门和返回牌复用现有木牌材质、真实脚点与牌内排字方法。牌面、箭头、中文在同一局部构图中移动和缩放，字留在钉头内边距；不得把“驿后练场”悬在另一处当漂浮任务名。标牌初定位仍受正式入口几何约束。相机改变、手机DPR和Mac字体替换后都核对字仍贴牌面。

归驿仅在玩家当面报告真实经历后，在桌案已有纸面体系中添一张小练习记；首次报告才出现，后来只补已报告的新事实，不覆盖原有旧渠、认路和小集笔迹。纸面可用来向短笔与侧步/小弧/触点作克制区别，详细意思由桌边短句解释。没有预印的三方向空槽催玩家刷满，也不把未报告的facts、刚选的来向或收手未发射画成完成。共同笔迹、许照见证与能力掌握称号均不出现。

同一手的“被碰到”可以如实留下，不做污损整页的惩罚。重复相同报告不添第二张奖状；纸图仅说明做过什么，不能暗示额外数值收益。

## 声音与各模式的招牌时刻

近处为石地脚步、收袖衣料、手前短聚音；远处为轻风和稀疏枝叶，仍能听出在驿后。沿石驿的疏落拨弦动机，留更多停顿，不加擂台鼓点、欢呼人群、倒计时蜂鸣或师门考核音乐。没有新语音；闻朔的意志由站位、动作、短句完成，不模仿动漫声线。

功能声次序：真实起手/来弹/承击或受伤优先，随后收势和脚步，最后环境与乐声。护符展开与真正承击不同，收手与真结清不同；若暂时没有专用收手音，宁可用收袖动作和短句，也不复用成功和升级音。读档、重复看结果和暂停不能重播一手的发射/格挡音。静音下保留动作、弧形、接触点和短句。

| 实际模式 | 玩家动作、压力与第一焦点 | 输入前后、界面和声音 |
|---|---|---|
| 驿里出入 | 玩家先与实际同行的许照约好等候，再从后门进场 | 熟悉院子里她在原脚点停下；入口短对白结束后玩家独自走出，没有复制旁观人。 |
| 近身约定 / 绕行定位 | 玩家选另一来向，侧身让出闻朔的路 | 同一个人沿圆外真实走过去，遇到玩家停脚；脚步续起比“准备完成”弹框更先说明变化。 |
| 相向一手 | 看抬手，选择侧步或对准护符 | 人、手、弹、脚边线同屏；真实承击一声脆响，侧身后留空的来向说明为什么没有碰到。 |
| 主动收势 / 余弹 | 玩家收手后仍走开 | 闻朔手已落下，唯一旧弹仍从两人之间经过；镜头同尺度跟随玩家，短句提醒余势，直到真结清才恢复平静。 |
| 暂停与续存 | 玩家在起手或余弹中暂停、保存再回来 | 人物与弹停在同一处，打开的护符朝向不变；恢复接原动作，无重开音或恢复资源光。 |
| 受伤 / 资源不足 / 再约 | 玩家近身再问，体力不足时自己离开 | 闻朔原地收手说明当下原因，返回牌仍可见；没有免费重建初态按钮。异常败退只沿已定完整落点恢复文案，不伪装正常“再来一手”。 |
| 桌边回响 | 玩家亲自回驿说刚才的一手 | 原桌上添有限笔迹，一句如实回应；没有积分、排行、三项全满或强制继续练习。 |

## 移动与视听的未验证风险

优先看三类真实局面，而非先铺满原画：正面相向的一手、左右换位时经南点绕行、收手后玩家带着余弹离开圆心。每类都应能看出谁在行动、弹从哪里来、脚还在哪里，以及当下是否已经结清。

- **上下相向失真：** 左右翻图能让侧向成立，却不能让正面朝南/朝北成立。以实际手位、头肩方向、术法出现点联合核对；不能只验一个flip布尔值。
- **矮窗或手机裁脚：** 600×600必须落在真实HUD可用区。南点姓名、手前光、暂停提示和护符触控目标不能挤掉人物脚或把点击送进UI。
- **边线与余量误读：** 脚影、衣摆和身体余量容易混淆；图中不得把“还看得见衣摆在线内”宣传为合法站位。用真实走到边缘的停因与画面一起核对。
- **画面提前结算：** 收手立刻散弹、边线闪绿、远程弹结果对白、自动切回入口都是否决项；尤其看收手/越线后的实际hurt仍可读。
- **多处姿态覆写：** 新闻朔帧、通用敌人步态、起手光、暂停读取可能互相覆盖。只一个实际角色，不留旧敌头像/名称；只对真的移步推进走动画。
- **省略碰撞却制造障碍：** 围廊柱、器物和大型石块若伸进中央或绕行带，会让玩家无法预测能走哪里；反向也不能把有碰撞的外围墙画成平地。
- **源图清楚但运行模糊：** 检查当前DPR与5MP上限下的实际画布、角色手向、粉线和中文；不能只提交一张放大的素材图就宣称手机无像素感。Linux仿真与真实Mac/Safari证据继续分开。

这些是制作与验收条件，不是本文件已通过的测试结论。本轮仅交付局部方向，下一批资产和正式运行由根代理安排；无需再为已确认的世界风格、独自练习或同伴等候重复询问用户。
