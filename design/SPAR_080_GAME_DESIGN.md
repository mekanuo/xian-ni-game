# 驿后练场 · 正式局部设计

2026-09-11。延续已批准的空间冒险/原创散修身份，依据SOURCE_BIBLE与SOURCE_SCOPE的早期凝气/山门之外结构。闻朔、练场、约定及交流均为open原创，不使用王林独有法宝/成就。不重新设计全书或改全局美术风格。正面、左右来向和连续两轮真实输入已成立；根代理依据持续自主开发授权与存档评估收束本稿，批准进入生产；**不是已实现的新地图**。不覆盖原版 GAME_DESIGN。

## 玩家为何来，来做什么

首章取回并试过控物环、实际归驿后，可从驿后小门进入练场，不要求完成市场，不替代其他支线。入口使用既有首章归来事实，精确谓词沿现有endingWish/结局记录核对。闻朔是也在适应山外行路的同阶散修，愿意互试基本步法；他想试不同来向，玩家想知道自己在路上是否留得出退步地方。

这是可自愿反复尝试的小活动，不包装为大章、长篇师徒线或突破境界。熟悉操作的人可能几分钟体验完；不以耗时、地图数量、打空血条或刷经验证明内容价值。退出不封后续路，失败也能如实回驿交代。

玩家实际走近约定正面/左侧/右侧来向，闻朔自己走到相应位置，玩家站在线内，再确认开打。每次只出一手：步法侧身、朝向明确的护符、首次被碰到、踩出线、主动收手都是可解释的结果。两人还有自己的事，结束后闻朔收势留在实际脚点，玩家须走近才能再约或交谈；不把人变成永久战斗随从。

## 空间与人物

暂保留已验过的练习坐标：圆心(900,940)，半径70，脚心留17单位余量；正面(900,720)、左侧(680,940)、右侧(1120,940)。场外围四个约定站位形成绕行路线，南点(900,1160)。约定/交手镜头局部600×600、中心(900,880)，不在交手时突变缩放；自由探索时跟随玩家，定位时平滑移向练场；收手后余弹阶段保持当前缩放并跟随玩家，避免走出画面；结清后平滑回普通探索镜头。手机按宽高保留人物/起手/安全触控空间。正式全图拟1800×1400，受测中央范围保持开阔，围廊/树石/木门仅在外围，不加会让人站角等赢的内墙。

初进场玩家从南侧步入，出入口约(900,1280)，闻朔招呼位置(900,980)，双方先走近。实际入口定位、碰撞与画面须实测后定，不把拟定坐标当成已验收。回石驿拟在东侧后院通路加实体小门与清楚路牌，不替换“驿后空屋”的既有用途或挡住去溪道的主路。地图名“驿后练场”，对白不用生造的术语。

许照若在石驿实际同行，入场前明确选择“约她在驿里等候，再独自入场”或“继续同行，先不去练场”。等候保留她当时真实脚点，返回不自动恢复同行；可照旧走近再邀。本来在别处等候或拒绝时完全保留，不移动、不复制。练场不新增许照实体，不允许 following 状态进入；不把旁观写成共同见证。

定位阶段走既定圈外路径；若闻朔前面有人，会停步等让开。不能穿过站定的玩家、突然跳位置或改全局NPC为实心。玩家主动挤到普通人物身上的既有规则不在此扩展。场内开始前和结果后的动作应有近身招呼/转身/退手，不靠一张结束牌代替收势。

## 已通过的回合规则

- 双方体力至少2，无在途术法、未发火球、暂停待办或牵物，才同意开始。玩家未到位、NPC未到位不发射。同一真实实体和资源连续保留。
- 一手期间只允许步法与护符；先收手且余弹结清后再做其他动作。不得扣到零才算输，也不临时改敌弹速度/旧护符覆盖/玩家消耗来凑过关。
- 真实玩家移动之后、敌人发射之前检查越线；首个停止原因保持。已经飞出的那一发继续首碰撞，不能被对白/出图/重置抹掉；余势未清时只给短提示，玩家仍能走开。
- 未受伤且未越线，以真实block分“护符承住”，否则必须真实发射并自然结清后才是“侧身避过”；站定挨打、沿弹道退步都不是成功。按下护符不是格挡证据。
- 失败、再约、退出不回血/回灵力。HP1拒绝下一手；可离场按既有正常方式歇脚或用物，不在练场提供免费重建初态。正式游戏没有灰盒的资源下拉与重开按钮。
- 左右侧面的应对沿射弹实际方向，不把90度临界作为教学保证。对照用明确背向来弹的护符，略前方的斜射仍遵守既有前半区覆盖。精确切线浮点误判的窄修复随正式版回归。
- 主动火球打断闸口已否决，约0.1秒反应窗不符合正常体验；不得悄悄恢复“抢先发火就过”的假成功规则。

## 世界会留下什么

先保留有限、能对应实际动作的事实：见面/约过哪一边、哪一边真正避过/挡住/被碰到。成功不发永久属性、货币或材料；重复相同结果不重复奖赏。失败也有具体一句回应，如“这次从你右边过来，护符却朝着另一边”，前提必须与实际朝向/事件吻合；若无法证明具体原因，就只说实际被碰到，不编造玩家为何失败。

回到石驿桌边可如实记下做过的一手，纸上逐笔留下实际来向与做法；不在仅参观/选择对白时画满三条线。尚未避过不说掌握，途中收手不说完成，旧记录不覆盖后来的当前资源/位置。已讲过的事实不再弹同样完成提示；尚未讲的实际经历仍可晚些回报。完成标记仅表示这一小活动的闭环，不要求三种来向全部刷满才允许继续旅行。

## 存档与边界（生产合同）

新增地图/实体/局部回合需要正式content版本迁移，外层与嵌套checkpoint都严格处理。支持旧0.7与更早已支持档续玩；不借迁移给HP/MP补满。主动练习保存必须保留已耗资源、射弹、位置、阶段与首个停止原因，，不能默默恢复到开场。

过门前必须结清余弹；靠近出口不是自动安全，不用通用changeScene清弹代替真实结束。暂停与失焦正常冻结，恢复不能重置起手/绕行；新约不能盖掉旧弹。保存/再次进场/重试/撤离须分别说明是否保留真实结果与临时回合，不借“点到为止”推断所有状态永不败退。

采用 SPAR_080_SAVE_INTEGRATION 的单一 run + last 状态结构与稳定 enemy 身份局部交谈例外；不复制 GameState。正式 tick 同一个小步先检查越线/撤手，再推进敌人与余弹，最后结算，不套一层重复 tick。v7 八图迁移先严格验证旧来源清单，外层与单层 checkpoint 各自独立迁移。

追加有限 facts 与 reported 集合：三来向 × dodged/blocked/hit，共九种事实，去重且 reported 必须为 facts 子集。last 追加 hurt 布尔值，记录收手或越线后仍被余弹碰到；此时可记实际 hit，但不授予成功。未发射便收手不新增九种事实。首次真实经历在桌边记下即闭环，不以集齐九种为目标，不加等级或奖励。

练场内一直拒绝火球与牵物；活动中拒绝治疗、静息、香囊以及通用 retry/retreat。空闲时可按既有消耗用伤药，不能静息。正常结果只允许近身再约或亲自离场。合法一源回合体力至少 2，首次损伤即止，不会体力归零；若异常 defeated 发生，只提供明确“恢复上次完整落点”的局部 retry，恢复整个合法 checkpoint 的实际 HP/MP，不补满、不局部拼接。没有有效 checkpoint 则拒绝并保留当前状态，手动存档导入仍可用。旧地图的败退合同不改。

只在清洁入场与已结清一手之后写自动 checkpoint；手动导出支持定位、起手与余弹中途，恢复不模拟、不重排路线。场内永不成为 lastSafe。

## 正式视听与验收门槛

沿石驿和集口的明亮手绘斜俯视、动画化成人Q版尺度，灰青石地/暖木围廊/草边，中央留出清楚可走的练习地。新闻朔造型需要同尺度的招呼、行走、抬手、停手/等候状态；当前灰盒借用敌人图不作为最终人物。路牌中文在真实牌面位置由代码清晰排版，不把汉字烘在背景图。

术法光、手势、脚下边线与实际碰撞一致；不用用户指出拉低质感的白色操作连线。起手/发射/格挡/被碰到/收手要可区分；声音用既有原创体系衔接，不能只加响亮爆炸代替打击反馈。手机DPR/触控、Mac尺寸视口都测，但没真机就不声称真Mac/Safari已通过。

生产完成需：真实新旧档出发→进场→不同做法/失败/收手→连续再约→同行或缺席→实际归驿记事→保存再读的闭环，全部既有章节回归通过；原URL发布后同源资源、输入与新活动入口核验。每阶段提交推送。灰盒通过允许进入这份生产设计的收束，不等于已发布或已证明长期好玩。
