# 0.6 石坳代表局面复核：否决当前章案，缩小验证问题

2026-09-11。**草案评审，不是已选设计、实施计划或白盒批准。** 承接 [OUTSKIRTS_060_SKETCH](OUTSKIRTS_060_SKETCH.md)。本轮结论：石坳的双出口目标有用途，但“借低工道／独走高径”尚不能形成有区别的决定，否决以此组织 0.6 整章。没有因此安排新地图、美术或新系统；0.5 发行与 QA 仍由当前交接控制。

## 1. 本轮要证明的事

玩家从同一站位看懂现场条件，选择一条路；条件改变时，有理由改走另一条。变化必须来自可观察的空间事实和现有动作，不能来自奖励数值、强制绕远或人物反复收回许可。

沿用既有研究入口 [SOURCE_SCOPE](SOURCE_SCOPE.md)、[SOURCE_BIBLE](../docs/research/analysis/SOURCE_BIBLE.md)、[GAME_DESIGN](GAME_DESIGN.md) 和 [ROLEPLAY_DIRECTION](../docs/ROLEPLAY_DIRECTION.md)，不补小说原文或未确认时间线。恒岳与王林的经历属 immutable；观察试探、议约与有限合作属 adaptable；石坳、岑立和地理连接均属 open；宗门变故的精确日期与当地损坏成因仍属 conflicted。

## 2. 用一个完整局面检查原案

固定局面：溪道一侧的背坡是安全观察位；眼前低工道绕过石壁，岑立的卸料面占着它的内侧；高径绕到同一块石壁的外侧，其边缘靠碎石槽。两路在旧渠西高岸出口前汇合。岑立在卸下、分拣薄石片，不跟玩家移动，也不负责替玩家确认出口。玩家可以从入口撤回。

必要信息应在入险前可见：卸料的实际落点、低工道的两个退身处、高径上不进入碎石槽的立足面。看不见的盲弯不能用对白直接判成安全；人物只知道自己何时卸料，不知道下一次天然落石。

| 尝试 | 行动与后果 | 为什么不足以成立 |
|---|---|---|
| 合作借道 | 当面叫住岑立；他把手中石片落稳并暂停，玩家确认退身处后过低工道；过完他继续工作。 | 作业理由成立，但空间问题被一句许可消除了。再加整理两件轻物，只把许可改成搬物门锁。 |
| 独行高径 | 不占工作面，从观察位看碎石槽，走背坡安全线；贴槽快穿则用现有定向护符承担一次可预见来石。 | 前者只是安全绕行，后者仍是已用过的窄段危险与护符时机。以更多来石、伤害或更长绕路补差别不成立。 |
| 让作业改变安全线 | 卸料时低路危险，停工时低路安全；让玩家在两种时刻选择。 | 等岑立停工便取得安全短路，等待本身没有新的空间判断。禁止等候或加全局倒计时会另造压力。 |
| 牵轻物或施火清出低路 | 挪走临时挡物，或者烧掉挡物后通过。 | 若挡物唯一功能是堵路，仍是开门；若挡物承担石堆支撑，则偷偷引入承重、坍落规则。 |
| 护符穿卸料面、近身砸石 | 不停工强行穿过，或打掉大石改变落点。 | 把方向防护扩成工程安全保证、把近身动作扩成采石，超出现有动作语义；也使玩家无理由地破坏人物工作。 |

原案不能给出“在条件 A 合作更适合、在条件 B 独行更适合”的可读证据。资源多寡只能改变容错；临时许可只能改变谁同意；两者都不能替代路线本身的区别。因此本轮不再给岑立扩对白、关系值、委托或奖励。

## 3. 双出口用途可以保留，但不为过程背书

仍可保留的地理问题是 **溪道外缘 ↔ 旧渠西侧高岸**。如果以后重新选用，必须同时做成两个进入既有场景的真实出口；接点、镜头和落脚地形尚未核对，不在此锁坐标。

- 从溪道侧进入，走出高岸侧后应实际位于现有旧渠安全岸上，能继续原有清渠、检查和取回借物等尚未完成的事情。过境不能代替任一清渠成果，也不能凭到达补出旧任务事实。
- 从旧渠侧进入，反穿后应回到现有溪道，再用现有通路去工棚或石驿。玩家从高岸办完事返回时可以选它，不必为了使用新图先接第二次委托。
- 两端均可进入和撤回。到访、走过低路、走过高径、请求过许可、真正跨过出口分别成立；只有亲自跨出的出口才算通达。新路不能跳过尚未完成的章节入口要求。
- 已完成旧渠事务的玩家可以把它当联络路，但这不保证值得反复走。若它只增加一段路而没有不同的通行条件，也不能靠路图奖励宣布返程有趣。

这是连接的最低用途约束，不是连接已选或已实现的声明。NPC 工作与双出口都合理，仍不足以救回上述局面。

## 4. 更小的新方向：留下遮蔽物，还是烧开视线

建议下一轮只讨论一个空间问题：**同一块普通遮蔽物既阻挡来袭，也挡住玩家观察和施火的直线；去程打开的通道，返程是否会因此失去掩护？** 暂称“背墙两面”，不命名新章节，不添加岑立或其他工作人物，不以此替换完整 0.6。

最小场地仅需一段折墙、一个可绕至另一面的掩体、一块已落地的轻质挡板、一个现有类型的远程敌人，以及两端都能退回的通行口。两口首先只是验证场地的边界，不冒充已接入溪道与旧渠的正式出口。敌人不在返程复活；若它已被击败，返程变安全就是实际结果。

空间条件必须同时满足：挡板仍在时，入口侧能隔着它避开敌方直线，但也不能隔板看穿或施火；绕至墙侧可露出另一条射线。挡板烧毁后，原处可通行、可施火，同时失去原先那片遮挡。变化落在地面和视线关系上，不靠隐形危险区或一句“这里更危险”。

| 可读初态 | 可尝试的决定 | 应出现的空间后果 |
|---|---|---|
| 敌人在挡板正面，玩家将绕到侧面 | 保留挡板，利用折墙换观察角度；有灵力时把落地挡板牵到另一处再放下。 | 挡板提供撤回位置，但从这里直接施火也受阻；移动它应同时改变双方射线。不能出现只挡敌人、不挡玩家的便利规则。 |
| 玩家已绕到敌人侧后，旧挡板挡住直接退路 | 烧开挡板取得通行和施火直线，或沿原折墙撤回并保留遮挡。 | 开口是持久的；若玩家未击败敌人，反向回来时不能再借原板躲避。是否值得烧取决于实际站位及敌人是否仍在。 |
| 零灵力或不愿战斗 | 沿折墙观察、退回或从有硬掩体的侧路绕过。 | 能完成穿越且可撤回；不能把这条路故意拉长来衬托施术。若它在所有位置都同样顺手，则直接判定选择仍被支配。 |

护符仅用于一次方向正确的暴露穿越，近身仅在实际接近敌人后使用；都不是通行钥匙。牵着的板不能被默认写成随身盾：目前牵起与落地的碰撞语义不同，此方向只讨论**放下之后**的遮挡关系。挡板能否同时阻断双方视线、火和来袭仍需逐项验证，本文不把材质画成墙就宣称这些效果存在。

这个小问题比石坳原案多出的可能性，是玩家亲手改变了下一次接近同一空间的条件，而非完成修复后永久消除危险。但它还没有成立的工作人物与合作理由，也没有证明安全侧路不会支配其他走法。因此只保留为下一次选题验证问题，不能包装成满足本轮全部条件的石坳章案。

## 5. 继续或丢弃的边界

在另行决定开展验证前，只需用同一小场地回答三件事：能否从安全位置看懂双方射线；敌人仍在时，换一侧接近会不会使保留／挪动／烧毁的选择发生变化；这种变化是否超过已有“声响引敌后绕行”的体验。

以下任一情况出现，就丢弃该方向，不补更长路、第二名敌人、复活机制或数值奖励：

- 不看掩体关系，始终走安全侧路就同样顺手；或始终烧板总是更好。
- 选择只取决于有无灵力，和接近方向、退路、敌人实际位置无关。
- 需要新增可携带盾墙、复杂破坏、敌人工作区保护或新的 NPC 救援剧情才勉强成立。
- 必须让返程敌人凭空复活，才能证明去程拆板有后果。

本轮交付的是否决依据和一个更小的问题。**0.6 仍未选题，不安排石坳生产；没有新的用户确认项，也没有实施、浏览器或趣味验证结果。**
