35文件749测试、整版29条命令及六项核心判据全部PASS；139个输入与29个发行文件冻结指纹复核成功。公网29资源逐字节匹配受测构建，实际键盘/触控、声音、旧档续玩检查exit0；新章公网从固定0.6旧窑完成导出到集市与沈砚交谈exit0。记录见 `qa/verification.json`、`qa/evidence/publication.json`、`qa/evidence/market-public-view.json`。完整双路线/归驿是在同字节本地受测构建完成，公网补的是新章入口冒烟检查，不称第二次公网全程通关。

「集口问路」新增一处可实际往返的小集。完成认路并归驿记下后，可从石渡彼岸进入，北口接到旧渠。你可以沿公共巷自行通行；如果亲自穿过旧窑，也可以向沈砚交换路况，请她打开私巷木门。她会亲自走去解闩，眼前出现威胁时会停步，局面缓和后继续。

走到另一侧出口、真正离开之后，经历才会记成通行。回石驿的桌边可把亲自走过的路线记下，去程和回程分别保留。原口折返、走到门边或仅听到开门承诺，都不会被当成走通。

手机增加「看路」按钮：开启后拖动画面查看远处，再次点击恢复行走点选；「回到身边」让镜头重新跟随角色。可以先暂停看清道路，再继续行走。

许照可以留在小集等候，之后再回来会合；她在这里时，其他地图不会再出现另一个她。旧存档继续保留已有道路、物件和资源。真实败退后的重试与撤离分别恢复检查点或保留已经发生的交换、开门，不会补写没有完成的通行。
