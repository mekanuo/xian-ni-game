# 0.8.0 · 驿后练场（发行候选，尚未发布）

当前公网仍为0.7.0。此文记录候选范围，不能替代冻结构建的完整验证报告。

首章归来后，可从回石驿后门进入独立练场，与原创同阶散修闻朔自愿约一手。选择不同来向后双方实际就位，再示意开始；可用步法或护符应对，也可提前收手。已经飞出的来袭仍会结清，受伤与灵力消耗带回驿中。此处不奖励经验或要求刷满结果。

许照同行时，入场前需明确约她在驿里等候；她留在实际位置，归来不会自动替玩家作出重新同行的决定。实际练习事实可回桌边记下，重复报告不重复奖励。历史存档经严格校验后自动迁移，定位、起手与余弹中的手动保存保留真实状态。

美术使用独立闻朔角色、原玩家背向姿态和与石驿材质一致的灰石练场；练习期间镜头覆盖双方与南侧换位空间。保留既有声音系统，实际受击与格挡分别触发对应反馈。
