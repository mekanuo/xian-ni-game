# 用户已认可的角色扮演修正

2026-09-09最新讨论结论。它修正CONCEPT A的重心，不改变网页平台，也不是已实现的功能清单。

## 核心

玩家不仅解决场景问题，还要逐渐形成“我的修士惯于怎样办事、为什么修行、愿意回到哪里”的感受。空间战术提供行动基础，不能退化为仙侠机关题。

## 五项设计要求

1. **有生活起点与追求。** 开场有具体牵挂、已有本领、想改变的处境；不能只叫“年轻修士”就接任务。出身改变可观察的信息、做事途径及人物接近方式，不只加百分比。药铺学徒是讨论中的举例，尚未锁为实际出身。
2. **成长形成惯用路数。** 少量能力与法器先形成不同做法。玩家应期待取得适合自己的东西、学会可组合的新本领；行动表现也变化。不预设几十个流派，不以伤害数字代替全部成长。
3. **关系包含共同生活。** 一起赶路、谈一件物件、讨论修行、返回后提及共同经历。NPC有专长，会主动帮忙也有底线。不能只靠悲惨处境、求救和交易让人喜欢。
4. **有熟悉的落脚处。** 人认得你、留物仍在、上次事件改变某人的安排。无需膨胀成完整经营系统，但返回必须与第一次来不同。
5. **明确的快乐，不持续受苦。** 熟练施术、取得合用物件、获得真诚认可、发现隐秘去处、漂亮地解决难题都是正向体验。不是每五分钟强迫痛苦道德选择，不靠亏损与等待制造深度。

## 首版体验问题

- 玩家能否描述自己的惯用办法，而且这种办法实际有用？
- 是否有一个人或地方，使玩家没有奖励也想再去？
- 结尾能否产生一个具体期待，而不是仅看到未解锁按钮？

以上要靠真人操作和反馈验证，不能由测试自动打PASS。

## 本轮一手研究依据

- [Obsidian：Pentiment介绍](https://www.obsidian.net/news/obsidian/obsidian-entertainment-announces-pentiment)：明确主角身份，教育背景与生活方式由玩家塑造，行为影响社区。借身份进入生活的方式，不复制其故事和背景。
- [Larian：BG3社区更新22](https://baldursgate3.game/news/community-update-22-wield-the-power-of-a-mind-flayer_75)：能力影响行动与对话，追求力量与同伴接受程度相连。借成长和人物反应的联动，不照搬寄生虫或职业体系。
- [Obsidian：Tyranny介绍](https://tyranny.obsidian.net/)：社会身份带来权力、责任与基于行为的声誉。借具体身份约束，不让原创修士从开场拥有裁决天下的权限。

这些是开发者资料研究，不是声称亲自完整试玩。具体场景和数值仍须设计、原型及用户试玩验证。
