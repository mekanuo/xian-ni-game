# 《仙逆》1561—2047章研究审计

## 0. 审计结论

这份文件审计的是上一轮研究的证据基础，不是重新提交一份逐章分析。

结论很明确：上一轮工具命令扫描了原文中第1561章至第2047章的章节标题序列，并定位了该范围的起止位置；上一轮模型实际看到的范围内，几乎没有章节正文。上一轮输出中的阶段划分、人物关系、修炼规则、因果回收和游戏化场景，主要是由章名、卷名、已有上下文和模型概括生成的推断，不能标成逐章原文结论。

因此，本文件把证据分成三类：

- **直接证据（D）**：上一轮工具输出中可见的原文信息，主要是章节标题、卷名和边界位置。
- **角色陈述（C）**：上一轮工具输出中可见的角色对白或角色自述。上一轮在本范围内没有形成可核验的角色陈述摘录，计为 **0条**。
- **推断（I）**：根据标题序列、上一轮回答中的概括，或尚未由逐章正文验证的结构判断。

本轮为核验结尾，另行直接读取了原文第251205—251675行附近的2044—2047章正文。这是本轮新证据，**不追溯计入上一轮直接证据**。本轮补读确认：2044/2046、2045/2047高度相似，但存在章节标题、分段或排版差异；至少在当前文本版本中存在结尾重复/近重复收录问题，不能仅凭标题把它们当成四个独立推进节点。

“`sed` 读取了194360—251700行”不等于“上一轮逐字阅读了194360—251700行”。管道中的 `rg` 只把匹配的标题行输出给模型；因此，上一轮可见的是标题索引，而不是这些章节的连续正文。

## 5. 不应继续复用为“已证实”的上一轮表述

以下类型的句子，上一轮写得像事实，但证据不足：

- “本源是高阶力量的基本语法”；
- “资源具有位置属性/附带关系成本”；
- “王林从界内第一人转成仙罡外来者”；
- “天运子、太初、默灭共同改变真相定义”；
- “李倩梅以接受无法拥有完成情感线”；
- “结局的胜负不是谁更强，而是谁仍记得约定”。

这些句子可以作为分析假设或专题标题，但不能作为上一轮已经逐章验证的研究结论。要升级为直接证据，至少需要补充：章节号、原文位置、短引文或准确的情节复述，并标注这是角色陈述、叙述者陈述，还是分析者推断。
