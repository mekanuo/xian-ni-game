## 弧一：化凡落地，借三种意境校准自我

- **范围与边界**：第251–254章，源文件行 `29533–29981`。
- **事件起点**：王林已在京都化凡六年，主动改变外貌以匹配凡人寿命变化，停止打坐和修炼，经营木雕店并以街坊日常体验凡人感受。多年未见的龌龊老头出现并认出他，指出这不是外貌伪装而是已近乎真正化凡。证据：`29535–29569`、`29621–29643`。
- **关键转折**：老头把王林带到白云宗，以草帽遮蔽身份，击破护宗阵；王林以普通飞剑变形为钟鼓兽，故意不使用惯用法宝，直接承受中年文士神通中的“绝情”意境。证据：`29757–29865`。
- **终点**：老头以祖灵牌交换白云宗三位化神修士的意境体验。老妪的安逸意境使王林几乎沉迷，煞气血球将其拉回；青衫老者的岁月意境使王林感到灵力生命力快速流逝。回到店铺后，他开始以木雕复现绝情意境，但仍承认成品有差距。证据：`29873–29975`、`29983`前的章节收束。
- **角色与目标**：王林的阶段目标是通过真实凡人生活找到自己的化神路径，底线是不让凡人权势和无关争斗破坏化凡；老头的目标是让他体悟多种化神意境，同时索取木雕；白云宗三位修士各自以自身人生形成意境，并受祖灵牌约束出手。
- **可游戏化冲突/选择**：玩家可在“保护化凡状态”和“主动暴露于高阶意境”间选择；可选择是否使用禁幡等防御资源、承受多深的意境、是否接受祖灵牌交易；木雕是观察和再现能力的反馈媒介，而非简单收藏。危险来自意境侵蚀、对手反制和身份暴露三者叠加。
- **规则/资源**：
  - **正文事实**：草帽含有复杂阵法并可遮蔽身份；老头可大范围瞬移；王林的煞气血球能在安逸意境中强行唤醒他；木雕可保存对修士外形与意境的部分观察。证据：`29767–29775`、`29895–29901`。
  - **角色陈述/叙事说明**：老头说元婴到化神需要化凡并感悟意境；他将自己的能力称为癫狂之境，并说明化神期只能在法术中带出较弱意境。证据：`29649–29717`。这是可追溯的解释，不等于所有化神修士都已被正文验证。
  - **研究推断**：可形成“承受/防护/记录”三路选择，但不能把一次白云宗体验直接扩写成普遍的意境训练系统。
- **因果/证据链**：化凡六年的持续日常使王林能识别并承受意境；白云宗体验提供三种对照样本；绝情木雕失败使“复制他人意境不等于拥有自己的意境”成为后续问题。关键位置：`29553–29569` → `29797–29925` → `29959–29975`。
- **可信度与边界**：
  - `immutable`：王林在此时仍未化神；三位白云宗修士分别呈现绝情、安逸、岁月倾向；王林以煞气血球脱离安逸意境。
  - `adaptable`：意境体验的交互形式、木雕反馈和代价呈现。
  - `open`：王林自己的最终意境在本弧未确定。
  - `conflicted`：老头对化神期意境强度的说明带有其自身以更高修为催动意境的例外，不能把本次癫狂之境威力作为普通化神基准。

## 弧二：暮年、师徒化凡与雨鼎索取

- **范围与边界**：第255–257章，源文件行 `29983–30335`。
- **事件起点**：王林继续化凡十年，外貌步入暮年，木雕停滞在无法复现岁月意境；大牛已成家并照料他，整条街的店铺则因欠租与转让逐渐成为王林的产业。证据：`29985–30051`。
- **关键转折**：徐涛重伤求救，红袍筑基修士不分对象攻击王林和徐涛；王林只用一挥手召出许立国吞掉骷髅头，并因不愿破坏收尾中的化凡而放走小道士。周武泰随后带徒弟来访，先以比较化神和“百年之内”祝贺诱发心障，王林识破并反击。证据：`30055–30091`、`30229–30305`。
- **终点**：周武泰不再追杀徐涛，却要求世子三日内把雨鼎送到道观；徐涛由此确认王林的层级远超自己此前理解。证据：`30307–30329`。
- **角色与目标**：王林要完成化凡，不愿因凡人权势或小规模冲突重新进入杀戮；大牛把王林视作长辈；徐涛试图以长期侍奉换取世子一方的安全；周武泰借师徒关系化凡，同时把王林视为同层竞争者；小道士福儿依赖师父保护。
- **可游戏化冲突/选择**：玩家需判断何时介入凡人冲突、是否救助旧关系、如何回应带有心理陷阱的对话；与周武泰的对话不是属性检定，而是识别“比较心”和期限暗示的风险。雨鼎首次成为政治压力下的交换物，可做成“交付、隐匿、寻求独立保护”的后续分支入口。
- **规则/资源**：
  - **正文事实**：低阶攻击会被王林轻易反制；他可救活徐涛但选择不追杀红袍修士；王林以街坊欠债和租契积累了凡人社会资源，却不把这些资源当作修炼目标。证据：`30081–30091`、`30109–30127`、`30031–30051`。
  - **叙事说明**：周武泰的化凡路径被说明为以师徒之情育成近似父子关系，最终可能以杀死弟子完成“以悲入神”。证据：`30297–30305`。这是正文解释周武泰内在路径的叙事说明，不是周武泰当面对福儿公开的计划。
  - **研究推断**：对话可承载“祝福即诅咒”的信息风险；不能把“百年必死”作为已经验证的世界预言。
- **因果/证据链**：王林不杀小道士保住化凡心境；周武泰据此判断他是同层修士；王林识破比较陷阱后反击，迫使周武泰转向雨鼎要求而非直接报复。关键位置：`30081–30091` → `30255–30307`。
- **可信度与边界**：
  - `immutable`：大牛一家与王林的长期关系；周武泰名为周武泰；雨鼎被要求在三日内送往道观。
  - `adaptable`：徐涛求救和对话博弈的交互表达。
  - `open`：周武泰最终是否会杀福儿、何时达到化神，本范围未给结果。
  - `conflicted`：王林说“百年内小道士必死”既是针对周武泰的心理反击，又与叙事说明的化凡路径吻合；不能只按预言或只按策略话术处理。

## 弧三：轮回天道的越界体验与雪变预兆

- **范围与边界**：第258–259章，源文件行 `30337–30581`。
- **事件起点**：世子携徐涛向王林跪拜并留下灵石，王林仍回到店铺日常；大牛父亲死亡，王林用黑色花瓣凝实其将散魂魄，使其有机会在轮回中获得更好的归宿。证据：`30345–30377`、`30391–30405`。
- **关键转折**：王林从大牛一家二十多年生老变化中触及天道，神念升离土黄色星球，追寻遍及星空的力量根源；天运子警告元婴修为继续追寻会迷失，并将他推回。证据：`30413–30439`。
- **终点**：王林回到店铺后修为从元婴中期升至元婴后期巅峰，并完成带有岁月痕迹的青衫老者木雕；十年后雪域异常大雪覆盖四派联盟，黑木被雷劈碎，玉简要求修士备战，王林发现高空有被禁制隐藏的巨大裂缝且会吸扯神识。章节末出现规律敲门声。证据：`30447–30473`、`30481–30575`。
- **角色与目标**：王林要理解生老病死而不干涉凡人轮回，天运子以旁观者和提醒者身份阻止其过度追寻；大牛一家成为王林感知凡人时间尺度的关系锚点；四派联盟开始以行政动员和阵法应对雪灾。
- **可游戏化冲突/选择**：这是“深入未知规则还是接受被迫返回”的高风险探索节点；玩家可选择追踪力量源头、及时响应警告或保留心神。雪变提供全地图环境倒计时：裂缝位置、神识吸力、异常降温和玉简召集逐步提高压力。
- **规则/资源**：
  - **正文事实**：黑色花瓣可短时帮助凡人魂魄凝实；天运子一指可把王林的神念推回；意境体验使王林完成青衫木雕并获得修为跃升；雪来自虚无裂缝，不是普通云层降雪。证据：`30375–30399`、`30437–30465`、`30533–30567`。
  - **角色陈述/叙事说明**：天运子称继续追寻此等天道需极长时间且肉身会腐朽；王林随后把青衫岁月意境判断为模仿轮回天道。证据：`30437–30439`、`30463–30467`。后者是王林的认识，不是本范围独立验证的宇宙定律。
  - **研究推断**：可把裂缝吸力和返回窗口做成探索风险，但不能把轮回本源设计成已知、可收集的资源。
- **因果/证据链**：凡人时间经验 → 轮回天道越界感悟 → 岁月木雕完成与修为提升 → 王林具备观察雪变裂缝的能力。关键位置：`30359–30427` → `30447–30467` → `30523–30575`。
- **可信度与边界**：
  - `immutable`：天运子介入使王林返回；雪覆盖四派联盟且存在神识吸扯裂缝；王林达到元婴后期巅峰但仍未化神。
  - `adaptable`：轮回感悟的视觉化、探索路径和警告反馈。
  - `open`：轮回天道本源、天运星的可达性和天运子的真实长期意图。
  - `conflicted`：王林将青衫岁月视为轮回模仿，是他的判断；青衫老者真正意境效果在正文中真实存在，但其是否“非真正轮回”不能升级为客观结论。

## 弧四：拒绝联盟、杀戮复发与雨鼎规则公开

- **范围与边界**：第260–262章，源文件行 `30583–30877`。
- **事件起点**：周武泰在大雪中到访，确认雪是杀气与雪域传送裂缝造成，并邀请王林加入四派联盟；王林追问雪域为何选择这里，周武泰只给出“利益”这一层解释。证据：`30583–30677`。
- **关键转折**：周武泰离开后，四名元婴后期黑衣人奉四派联盟命令来清除本国境内两百年来的可疑者；王林不愿让杀戮破坏化凡，但在店铺外被围攻后重新化为杀星，以岁月意境迟滞剑网，先后击杀三人。证据：`30701–30773`。
- **终点**：王林在十步内追杀第四人，周武泰为保自身与王林关系杀掉最后一人；老头随后解释雨鼎、风雨雷电四仙门、古仙界碎片和仙界之气，说明雨鼎对化神以上修士与修真国升级都极有价值。证据：`30779–30877`。
- **角色与目标**：王林目标是保住化凡与未来修真机会，不接受成为四派联盟的弃子；周武泰目标是拉拢潜在化神者并避免与其为敌；四名黑衣人执行清除可疑者的组织命令；老头以信息和烧鸡换取木雕，并试探王林对仙门的兴趣。
- **可游戏化冲突/选择**：核心选择是保持隐忍还是出手；王林可使用岁月意境、禁幡、极境和吞魂，资源顺序影响风险与暴露度。周武泰的站队行为展示“旁观者也会改变结果”：他先不出手，后用杀人灭口证明不参与。雨鼎信息让玩家在个人突破、国家战争和进入仙门之间重新估值。
- **规则/资源**：
  - **正文事实**：岁月意境可使剑网迟滞；禁幡的禁气可摧毁宝伞金蛇；极境对元婴修士有效但对化神有上限；王林杀人后立即恢复暮年凡人状态。证据：`30735–30767`、`30781–30815`。
  - **角色陈述**：周武泰说雪域国是资源缺乏却升至四级的修真国，因此为利益入侵；老头说雨鼎持有者可在天道开启日进入四仙门，仙门通向破碎古仙界，化神后期以上法力波动可能使仙界碎片崩溃。证据：`30667`、`30841–30875`。
  - **研究推断**：雨鼎适合作为有限政治权限与高阶突破资源；其具体数量、出现周期、进入条件和“天道开启日”仍需后续正文验证。
- **因果/证据链**：周武泰未说全政治原因 → 王林拒绝加入 → 联盟清除令触发直接战斗 → 王林暴露杀戮底色 → 雨鼎从传闻升级为各方争夺的核心资源。关键位置：`30651–30681`、`30701–30815`、`30837–30875`。
- **可信度与边界**：
  - `immutable`：四名黑衣人死亡；王林掌握雨鼎与仙门的关键信息但此时没有雨鼎；周武泰确认四派联盟会把可疑者当作清除对象。
  - `adaptable`：战斗资源顺序、追杀路线、拒绝/接受联盟邀请。
  - `open`：雨鼎的总数、开启日期、具体持有规则。
  - `conflicted`：周武泰只说“利益”，老头则提供仙门/仙气层面的解释；两者不矛盾但信息完整度不同，不能用周武泰的简化说明取代老头的角色陈述。

## 弧五：雪灾升级为灭国信息，王林决定离开

- **范围与边界**：第263–264章，源文件行 `30879–31105`。
- **事件起点**：雪持续数月后，四派联盟布阵阻雪、征调修士和凡人清雪；法力清雪效果有限，凡人被强征，死亡和房屋倒塌持续发生。证据：`30923–30959`。
- **关键转折**：周武泰玉简告知四派联盟已经发现异常：通常雪域入侵前只降雪十日，此次已持续四个月，说明目标可能是灭国；邻国、所属五级修真国均不愿参战。证据：`30961–30999`、`30969–30981`。
- **政治信息转折**：四派得知雪域出现百年修至化神后期巅峰、被朱雀国招揽的女子；她加入朱雀国的条件是雪域升为五级并迁离贫瘠雪域，恰逢雨鼎在四派联盟出现，雪域遂可能把这里选作新国址。雨鼎来源和世子持鼎被四派判断为阴谋，但仍未证实。证据：`31001–31027`。
- **终点**：王林因三十多年居住的街道和凡人遭灾，决定完成最后一次木雕后离开；他到雪原搜集百年以上木料，周武泰暗中压下调查并亲自帮忙，随后王林开始雕刻自己四百年中杀过的每一个人。证据：`31029–31105`。
- **角色与目标**：王林的目标从“留在四派完成化凡”转为“完成最后一步并离开”；四派联盟试图清雪、寻求外援、准备灭国战争；邻国和五级修真国优先选择不介入；雪域女子的公开目标是为雪域取得新国址与等级跃升，但其真实身份在本弧尚由报告和政治推测传达。
- **可游戏化冲突/选择**：清雪不是英雄任务，而是资源与人口被战争挤压后的生存选择；玩家可决定帮助街坊、保持隐身、寻找木料或加入联盟。政治层的选择包括相信四派报告、追查雨鼎阴谋、接受外援阵营或趁战争离开。木料搜集将“离开化凡”转化为有风险的准备行动。
- **规则/资源**：
  - **正文事实**：雪对法力波动敏感，法力清雪效果甚微；四派用高空阵法阻雪、用修士和凡人以人力清雪；百年以上木料是王林最后雕刻的要求；周武泰可利用职权压下王林采木事件。证据：`30927–30957`、`31065–31085`。
  - **角色陈述/报告**：十日降雪是雪域惯例；四派据此判断此次是灭国之战；朱雀国是否默许雪域灭国，来自四派对历史记录和外援沉默的分析。证据：`30969–30981`。
  - **研究推断**：雪灾可成为持续环境状态、劳动力资源和政治合法性压力，但“朱雀国已默许”在本范围应标为未证实。
- **因果/证据链**：雪域传送造成灾害 → 四派征调全境劳动力 → 外援拒绝 → 雪域天才与雨鼎内幕曝光 → 王林不再等待，转向离开与终极雕刻。关键位置：`30923–31035`、`31065–31105`。
- **可信度与边界**：
  - `immutable`：大雪造成四派凡人和修士共同受灾；四派联盟判断战争可能灭国；王林收集木料并开始杀戮木雕。
  - `adaptable`：清雪劳动、资源搜集、外援谈判和离开路线。
  - `open`：雨鼎是否为有意投放的阴谋；朱雀国是否实际批准灭国；雪域女子的真实政治权限。
  - `conflicted`：雪域女子“百年天才”的身份和战争动机主要经外援/五级修士传回的消息建立，后续战场出现替身式白衣女子，说明这一身份链不能提前当作单一事实。

## 弧六：终极杀戮雕刻，生死意境与大牛救援

- **范围与边界**：第265–266章，源文件行 `31107–31351`。
- **事件起点**：王林按记忆雕刻从师父孙大柱、即墨老人弟子、藤厉开始的全部亡魂；随着木雕增加，杀气在店铺内外凝聚，四百年杀戮史与三十多年化凡人生同时回放。证据：`31109–31171`。
- **关键转折**：记忆收束为“生、死”两个概念；所有木雕和三个煞气血球凝成无面黑印，黑印融入元婴。王林走出居住三十多年的店铺，逐步从暮年凡人恢复成接近化神的修士，并确认闭关十年即可化神。证据：`31181–31211`。
- **终点**：王林在雪灾清雪营救出大牛和妻子，利用木雕留下的神念定位妻子，撕开两国边界光幕，把二人送入邻国并留下金银；大牛记住此恩，但终生无法再见王林。证据：`31213–31349`。
- **角色与目标**：王林要把四百年杀戮与三十多年凡人生存经验整合成自己的道，而不是复制白云宗意境；大牛要逃离清雪营找到妻子并活下去；王林对大牛一家的目标是了却长期因果，不公开仙人身份、不带他们回到修真冲突中心。
- **可游戏化冲突/选择**：终极雕刻可采用记忆选择与资源献祭：遗漏某个亡魂会改变黑印形成，但原作未说明可否遗漏；救援段落要求玩家用已布置的神念、木雕保温效果和边界破坏能力，在隐匿身份与及时救人间取舍。救援的成功不是复活，而是把人送到可继续生活的地方。
- **规则/资源**：
  - **正文事实**：百年以上木料支撑终极雕刻；木雕与煞气血球凝成黑印并融入元婴；王林以生死意境/道悟接近化神；木雕可保温并可预留神念定位；他能短时撕开两国边界光幕。证据：`31065–31069`、`31181–31193`、`31201–31207`、`31327–31335`。
  - **叙事说明**：文本把黑印解释为四百年杀戮中“死”的外在表现，把三十年化凡理解为“生”的经验。证据：`31167–31175`。这是叙事对王林道悟的总结，不应自动扩成所有修士可复制的合成公式。
  - **研究推断**：可把“生/死”做成两类长期记忆资源，但复仇清单的完整性、黑印的技能集合和生死意境的通用边界属于开放设计。
- **因果/证据链**：白云宗三种意境无法提供王林自身答案 → 终极雕刻回看杀戮与凡人生 → 黑印形成并推动离开化凡 → 既有木雕神念兑现为跨境救援。关键位置：`29959–29975` → `31107–31211` → `31327–31349`。
- **可信度与边界**：
  - `immutable`：王林完成黑印并离开京都街道；大牛夫妇被送入邻国；大牛最终无法再见王林。
  - `adaptable`：记忆回放、雕刻节奏、救援路线和保温木雕的反馈。
  - `open`：王林已形成的生死意境在战斗中的完整能力表；黑印能否再次拆解。
  - `conflicted`：文本一方面说王林“掌握生死意境”，另一方面又说他还需闭关十年才自然化神；应区分“心境/意境已成形”和“境界尚未完成”。

## 弧七：雪域战争展开，抢夺土灵并迎来真正使者

- **范围与边界**：第267–270章，源文件行 `31353–31828`。
- **事件起点**：王林送走大牛夫妇后没有立刻离开四派联盟，改以雨鼎为目标；他认为雨鼎是进入仙门、取得仙界之气的关键，并在雪峰下闭关等待雪域修士到来。证据：`31353–31383`。
- **关键转折一：入侵与战场规则**：一年后，雪域修士从高空裂缝降临，白衣女子下令进攻；四派以四方光柱、九十九个上古野人、四件镇派宝物反击。雪域修士利用积雪恢复灵力，冰雪巨人由元婴凝结而成。证据：`31385–31425`、`31479–31525`。
- **关键转折二：地下吸收与高阶战斗**：王林发现死者会结成冰雕沉入地下，被五千丈下的人首蛇身冰雕吸收；他发玉简示警后避开火灵。雪域降下三十六座冰雪塔，四座九十九层；四派化神修士出战，九人杀阵击杀了先前的白衣女子，但王林怀疑她并非真正天之骄女。证据：`31547–31589`、`31593–31687`。
- **关键转折三：苍龙与抢土灵**：一百零八道光柱激活天云山脉苍龙，周武泰因守护血脉操控苍龙；王林趁五行土灵被黑魂派年轻人追击时设伏，先用禁制和禁幡拖延，再用黑印与天逆收入土灵，代价是禁幡严重受损。证据：`31689–31777`。
- **终点**：地下冰雕全部升空并消失，中央裂缝降下可冻结万物的人首蛇身之物；真正白衣女子出现，要求朱雀国的“使者大人”出手杀苍龙，并召回其余四道五行光团，随后发现少了一个。第270章在此截断。证据：`31779–31827`。
- **角色与目标**：王林的目标是取得雨鼎相关机会、完成化神准备并在战争中保持隐蔽；四派联盟目标是守住家园、以镇派宝物和苍龙反击；雪域修士目标是灭掉四派并建立新国址；黑魂派年轻人追击土灵；王林把土灵视为补全天逆五行的稀缺资源。
- **可游戏化冲突/选择**：
  - **隐匿观察 vs 介入抢夺**：王林原本躲在雪峰观察，看到土灵重伤后才主动进入战场；介入意味着暴露、禁幡损坏和被高阶修士锁定。
  - **资源顺序**：禁制、禁幡、黑印、天逆和岁月木雕各自承担控制、拖延、压制、收容和伪装作用，使用顺序决定是否能在年轻毛笔修士追上前完成收容。
  - **政治与战场信息**：边界邻国封锁双方修士，胜者未决前无人可出；玩家无法把战争当作可自由退出的普通遭遇。证据：`31491–31495`。
  - **高阶战场**：冰雪塔层数、五行灵、四派镇派宝物和苍龙构成可读的战场状态，但层数与修为的关系仍来自雪域制度说明。
- **规则/资源**：
  - **正文事实**：雪域修士可用冰雪恢复灵力；元婴后可凝结冰雪巨人；化神后制作冰雪塔；三十六塔中四塔九十九层；苍龙需一百零八道光柱与周武泰血脉操控；王林收入土灵后天逆土属性圆满，禁幡出现更多裂缝。证据：`31485–31525`、`31599–31617`、`31695–31707`、`31745–31777`。
  - **角色陈述/叙事说明**：咒云称白衣女子可能是红蝶；王林根据雪域修士反应怀疑被杀者不是天之骄女；真正白衣女子声称朱雀国答应为她出手一次。证据：`31627–31637`、`31683–31687`、`31809–31821`。身份和政治承诺在本范围内应保持分层。
  - **研究推断**：地下冰雕可形成“战场死亡转化为未知敌方资源”的隐藏规则；土灵争夺可成为一次性高风险抢夺事件，但不能从一次成功推断所有五行灵都可安全收集。
- **因果/证据链**：雪灾预置战场资源 → 雪域裂缝入侵 → 尸体被地下装置吸收并触发王林警觉 → 高阶修士出场、苍龙阵启动 → 王林趁土灵重伤完成高风险收容 → 真正使者与未完整回收的五行灵把战争升级为更高层政治行动。关键位置：`31361–31383` → `31551–31577` → `31613–31777` → `31809–31827`。
- **可信度与边界**：
  - `immutable`：战争在四派联盟境内爆发；王林已获得土灵且禁幡受损；第270章末真正白衣女子出现并指出少了一个五行灵；人首蛇身之物正在降临。
  - `adaptable`：战争地图、塔层可读性、地下冰雕警报、抢夺时的资源顺序。
  - `open`：真正白衣女子的完整身份、朱雀国使者是否实际出手、雨鼎所在位置、地下怪物来源及五行灵缺失者去向。
  - `conflicted`：第269章的白衣女子被咒云/叙事说明关联到红蝶，但王林怀疑她是替身，270章真正白衣女子又证明两者外观与气质差异极大；该身份链必须保留为冲突事实，不能用单一标签覆盖。

## 源文件异常与覆盖备注

1. **第256章重复/异常标题**：物理行 `30099`为“第256章 糖人”，行 `30101`再次出现“第256章 人”。第二行不是新正文单元，随后正文继续到`30211`，下一章标题在`30213`明确为“第257章 百年必死”。本研究将第256章按连续正文计为`30099–30211`，并保留该异常，不把重复行误计为第257章。
2. **第270章边界与第271章标题**：第270章正文结束于`31827`，`31828`为空行，`31829`才是“第271章 红蝶”。本文件按用户指定范围止于`31828`，没有把第271章正文纳入证据；因此第270章末“真正白衣女子”的身份不使用第271章后续解释补全。
3. **正文中的作者更新/求票分隔**：范围内多处出现“第一更/第二更/求票/本章完”等连载元文本，例如`29667–29671`、`29759–29763`、`30331–30335`、`31081–31083`、`31823–31827`。它们保留在物理边界中，但不计为剧情事实，也不改变弧边界。
4. **叙事信息的冲突保留**：第264章的政治报告把雪域天才与战争因果连在一起；第269章先由咒云把白衣女子与红蝶联系，随后王林怀疑其为替身；第270章真正白衣女子出现并指出五行灵缺失。这里不以第271章的后续正文回填本范围结论，身份与政治承诺均标为`conflicted`或`open`。
