# 581–583连续补证

主线程于2026-09-09实际连续读取本地《仙逆》TXT源74094–74507：两块74094–74300、74301–74507，输出均完整，无重跑。物理581始74094、582始74224、583始74368、584始74508。此处只补原稿的明确读取证据弱段，不重复578–580或584以后。

## 581：判断威胁不等于知道威胁

- 红芒进入尚未开放的妖灵之地。天运子只能推得部分关联，凌天候担心贪狼，血祖担心惜雪；三个观察者的判断不是同一全知情报。
- 王林第十五声鼓后道心继续趋于圆满。仙力与道心融合存在死亡风险，本章尚未完成问鼎，不能按“朝闻道”说明直接记突破。
- 画舫青年认为是最简单雷罚、有九成把握，随后被事实推翻。红云红雷、阳春降雪和杀机先改变环境，禁幡风暴被雷穿透；王林借仙玉补给凝聚多道寂灭指。
- 空间从公开广场变成危及旁观者的灾区：震声已伤及观众，强者与普通人的承受差异明显。王林坚持自身道路，并不意味着旁人免受代价。
- 证据：74094–74223。观察、判断、投入资源与外部伤害是可提取结构；天逆、专属术法与原作功绩不交给原创玩家。

## 582：第一道成功不是整个危机结束

- 寂灭指只能削弱红雷；生之烙印转杀戮气、合苍龙仍不足。王林逆转自身及脚下仙玉的仙力，化魔指终于消去这道红雷。不是任意一击单独完胜。
- 天帅扔出药瓶后离开，王林拿到但未服；不能归因丹药治疗。旁白回顾称“百道黄泉”，与前段反复“寂灭指”存在术名异写，不据此另添一次黄泉施术。
- 青年发现红云未散、改判危险，想转移王林却因天劫锁定不能；改分八身挪走八个外城居民。明确转移对象不是无证据的全城所有人。
- 天威以云层逐寸下压体现，气浪被压回地面，宫殿、皇宫崩毁，妖鼓尚存。挑战从迎击雷光转为无处移动的压迫。不能把“高位者到场”直接结算全员安全。
- 证据：74224–74367；文末求月票文字不是剧情事件。可提取的是新证据促使改计划、救援受限后改救他人、胜利范围需分层确认。

## 583：救援带着请求和适配条件

- 五位古妖后代出地面，起初嘲笑天威，之后多次被压落；天妖城化飞灰，王林肉身经脉崩坏、埋入地底。不把人物自夸“不受天道”当无限免疫。
- 古妖向王林传念，自述族源、残缺及九郡相吞。其解释须保留说话者立场；要求取其他八郡圣物以换修复、渡劫援助及权限。
- 王林追问为何选择自己，古妖说明其古神气息使身体适合承力；不是所有修士都能获得同样附身增益。
- 王林要求修复并给予抗劫之力，随即肉身确实恢复、妖力入体、升空凝出双角紫黑巨影。到本章末只完成修复和借力，渡劫是否结束接584，圣物任务更未完成。
- 证据：74368–74507。原作行动结构为陷绝境后追问报价动机、接受带责任的援助；拒绝与替代解法并未在此被原文完整演示，不能凭此承诺游戏已有多解。

## 对旧稿的使用结论

问鼎尚待后文、普通雷罚判断被推翻、外城疏散、五老受挫、古妖的具体交换与身体适配，是不可删除的因果。此段不支持“连续用高阶术法即可独力完成全部渡劫”。原作城市毁损、受伤和他人援救应与成长一起记录，不只收录招式清单。

同轮另读7900–7940，共41源行，非581–583覆盖：95末明确五牌毁四留一，96开头又叙五块在手。矛盾确实在所给TXT中，不只是摘要误写；不擅补碎牌仍计资格、恢复或新得四牌的机制。最保守记录为曾取得五块，销毁后持有数的相邻叙述冲突，设计引用时标`conflicted`。
