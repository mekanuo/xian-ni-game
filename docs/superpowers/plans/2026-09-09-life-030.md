> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成首章之后，可在原四图亲手修稳挂扣、采回两类叶片，并得到一次性压扣与两份有实际用途的避兽药囊。

## Global Constraints

- 只用 home、creek、workshop、crossing 四幅现有地图，不增加新区域。
- 保留体力上限 4、灵力上限 6、两份伤药及原有静息规则，不增加经验、境界、货币、商店、日常或随机词条。
- 保留长牵 500 世界单位、普通牵引 300 世界单位、留势 8 秒与额外 1 格灵力。
- 两委托各只结算一次；压扣仅一枚，避兽药囊只发两份。
- 所有新增计时由模型 tick 推进，暂停、对话、菜单和失焦冻结。
- schema 保持 1，revision 保持 return-stone-v1，增加 contentVersion: 2；旧档与嵌套 checkpoint 同时迁移。
- 不新增 NPC 专用动作状态机；许照仅按真实同行、位置与关系回应，不记录未发生的共同采摘。
- 用户授权代理在约定范围决定详细设计并实施；该授权不是逐字确认所有参数。执行者自主完成约定实现与验证，不再询问使用内联还是代理的例行选择。

## 先核对的实际入口

| 当前接口/行为 | 实施影响 |
|---|---|
| model.ts `createGame(profile)`, `act(s,a)`, `tick(s,dt,input)` | 建立 life 默认值；所有功能经 act/tick 进入 |
| model.ts `choose` 校验当前 dialogue.choices，`dialogue` 每页两选项并自带 more | life 选项必须先出现在合法话题里；不要绕过旧分页/暂停恢复 |
| model.ts `interact` 与 `canInteract/interactionPoint` | 保留近身、遮挡与可达走位；life 不造远程操作入口 |
| model.ts `projectileTick` 实际命中 flammable | 在通用着火前识别炉芯；只命中才软胶，不因选了火术就推进 |
| model.ts `release` 和 stepTick 的留势到期都改 platformOpen | 新压扣支撑必须同时接入两处，不然松手即误关入口 |
| model.ts `enemyTick` 在 idle/searching 时提前返回 | 气味排斥必须在这些返回之前；否则只有追击兽会受影响 |
| model.ts `restore` 当前要求实体数量等于 SCENES.entities | 新增实体前先做精确版本迁移；不能仅放宽数量检查 |
| checkpoint() 保存 JSON 字符串且内部 checkpoint=null | 迁移外层与唯一内层；损坏或递归快照拒绝 |
| retry 完全还原，retreat 保留 current 世界和资源 | life 同样跟随；撤回额外取消即时工序，不保留领奖前后两份资源 |
| UI `SAVE/AUTO` 固定 localStorage 键、snapshot/restore 导入自 model | 不改键；model 可 re-export 新 save.ts 接口，旧调用不变 |
| UI `ended` 开一次 ending；关闭菜单不清 ended；tick 不看 ended | 续章解锁读 endingWish；不要强行清 ended 或反复结尾弹窗 |
| scene `renders` 按 state.worlds 实体建立，重画 key 目前只含旧 flags | 加 life 静态呈现 key，新工序/采叶/压扣变化才能立刻出现 |
