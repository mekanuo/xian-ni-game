# 0.2 首章玩法深化 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for sequential integration; independent files are delegated under AGENTS.md.

**Goal:** 让现有首章的空间组合、互动与多条解法更容易实际使用。
**Architecture:** model.ts唯一裁决规则；新encounters.ts提供只读处境和落点资料；scene.ts负责点击/预览，ui.ts承载可收起察看卡与收术。保留状态结构、旧存档和原有美术。
**Tech Stack:** TypeScript、Phaser3.90、Vite7、Vitest、Playwright/Linux Chrome。
**Spec:** design/PLAYABILITY_020.md

## Global Constraints

四地图、三术法、两种引环和原著边界沿用；不扩章、不跨境界；0.1.2画面基线；规则失败不得耗资源或改旧目标；真实浏览器证据禁止注入进度。
