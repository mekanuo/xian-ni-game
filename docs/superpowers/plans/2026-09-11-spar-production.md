# 驿后练场生产实施计划

依据 SPAR_080_GAME_DESIGN 与 BUILD_BRIEF_SPAR_PRODUCTION；已有自主实施/测试/推送/既有 Pages 授权，无新增待用户审批。根代理负责集成、浏览器、Git；独立美术文档代理只写自己的文件。

- M1 共用定位几何：先加独立三点绕行、南路、让路边界、输入不突变测试，再从已验白盒搬出纯几何；原白盒专项一并通过。
- M2 正式状态与场景：类型、纯状态与有限事实、八图模板；真实 act/tick 回合测试；source v6 清单冻结，v7 及旧层 checkpoint 独立迁移测试。不能用类型断言隐藏缺图。
- M3 世界接线：统一敌人身份交互资格、近身约定、待办重验、起手/余弹边界、同伴实地等候、回驿记事、无免费重试。模型与实际中途导出保持一致。
- M4 视听：正式美术、角色姿态、相向护符、镜头过渡、清晰中文与真实音效；手机/桌面真实输入检查包括移动出余弹镜头。
- M5 发行：全量适当回归、冻结 dist 与源码 SHA、旧档实际续玩、资源与公网实际入口。每个可审查里程碑 commit/push，不发布未完成中间场景。

实施时按依赖推进；原来的精确切线与绕行失败证据永久保留。缺陷先复现，不改测试预期掩盖规则变化。
